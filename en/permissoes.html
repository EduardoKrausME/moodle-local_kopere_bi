Permissions and privacy

Separate reporting access from administrative editing.

Capabilities

CapabilityPurpose
local/kopere_bi:viewView authorized dashboards.
local/kopere_bi:manageCreate, edit, import, export and manage dashboards.

Both are system-context capabilities and granted to the manager role archetype by default in db/access.php.

Reporting access is data access

Access to a page does not automatically mean access to every personal record returned by its custom SQL. Apply page capabilities and visibility, limit datasets, review export paths and test actual permissions using non-administrator accounts.

  • Restrict SQL authoring to trusted administrators.
  • Prefer aggregated values where personal detail is unnecessary.
  • Review filters, course scope and report exports.
  • Respect your institution’s retention and privacy policies.

External reading

The optional MCP integration enforces the MCP READ scope, local/kopere_bi:view, page access and feature switches. Access to other users or changing cohort filters also requires the relevant manage permission. See MCP integration.
