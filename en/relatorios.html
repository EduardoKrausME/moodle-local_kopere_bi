Report catalog and SQL compatibility

Bundled reports, MySQL/PostgreSQL variants and safe refreshes.

Database variants

Database-specific report definitions are provided separately for MySQL and PostgreSQL when SQL syntax differs. The installer selects the compatible variant; shared pages may contain database-specific blocks. From plugin DB version 2026102202, upgrades add missing variants while preserving customized SQL and settings.

php local/kopere_bi/cli/import_database_reports.php

Review existing definitions safely

Simulate updates before executing them:

php local/kopere_bi/cli/refresh_analytics_reports.php --dry-run
php local/kopere_bi/cli/refresh_analytics_reports.php

Existing customized SQL is preserved; stored SQL is replaced only when it matches a known prior checksum. Column metadata is merged to keep local formatting.

Limits and scope

Some reports use UTC day/week boundaries; quiz outcomes are based on finished attempts and grade history only includes retained Moodle records. Heavy individual-level queries are capped at 500 rows; narrow the dataset using course and period filters.
