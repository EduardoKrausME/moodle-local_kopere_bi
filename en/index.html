What is Kopere BI?

Kopere BI is a Moodle local plugin for building and viewing data analytics dashboards. Rather than relying on a single fixed screen, administrators organize categories, pages, blocks, elements, and filters to present indicators relevant to their institutions.

Visualizations combine interactive charts, tables, summary metrics, HTML, and maps. The catalog includes ready-made reports, database-specific definitions for MySQL and PostgreSQL, and learning analytics calculated by scheduled tasks.

Start with a practical workflow

  1. Install the dependencies and configure permissions in Moodle.
  2. Open Kopere BI from the Integrations menu in site administration.
  3. Choose an existing report or build your own page using blocks.
  4. Set filters and access rules before making individual data available.
  5. Monitor scheduled tasks that maintain tracking and analytics indicators.
