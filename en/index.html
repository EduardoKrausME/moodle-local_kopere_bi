What Kopere BI does

Kopere BI is a Moodle local plugin for visual, interactive reporting. Administrators organize categories, report pages, blocks, elements and filters to answer operational and educational questions using Moodle data.

It includes interactive charts, data tables, KPI cards, HTML elements, approximate IP-based maps, a built-in report catalog, MySQL/PostgreSQL report variants and scheduled learning analytics snapshots.

Getting started

  1. Install the required Kopere Dashboard component.
  2. Open Kopere BI from Moodle’s Integrations administration area.
  3. Start with a bundled report or build a page from blocks.
  4. Review filters, permissions and visibility before sharing.
  5. Monitor scheduled tasks that maintain analytics data.
