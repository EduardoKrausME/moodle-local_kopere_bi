REPORT 009

Course modules

Table counting course activity and resource module records, grouped by module type.

Report purpose

Table counting course activity and resource module records, grouped by module type.

Why use this report?

Helps administrators identify the most common activities and resources in Moodle, recognize course configuration patterns, and plan maintenance or training for the module types in use.

Actual filters Visualizations and SQL Limitations

Available filters

There are no dynamic user, course, cohort, or date-range placeholders in this query. The condition is fixed: cm.deletioninprogress = 0. The query does not restrict results to a selected course or require the course to be visible.

Visualizations and full original SQL

This report contains 1 visualization and 1 SQL query. Syntax highlighting preserves the original characters. Separate MySQL and PostgreSQL variants, where available, are displayed in their corresponding visualization panels.

1. Module count by type — Table

Table showing the module's translatable and technical names, number of occurrences, and a course field. The SQL excludes modules being deleted and groups the results by module type name.

Cache: 1h. Refresh: 1h.

Full original SQL

  SELECT CONCAT('lang::modulename::', m.name) AS lang_module_name,
         m.name AS module_name,
         COUNT(cm.id) AS module_count,
         cm.course
    FROM mdl_course_modules cm
    JOIN mdl_modules         m ON cm.module = m.id
   WHERE cm.deletioninprogress = 0
GROUP BY m.name
ORDER BY module_count DESC

Limitations and cautions

  • Counts are aggregated by module type across the entire Moodle installation, not by individual course.
  • The cm.course field is in SELECT but neither in GROUP BY nor an aggregate function. This may cause an error in PostgreSQL or MySQL with ONLY_FULL_GROUP_BY; when accepted, the course value may be arbitrary.
  • There is no dedicated PostgreSQL variant in this definition. The single SQL query is reproduced exactly as published, without guaranteeing it will run on every database system.
  • The count includes hidden modules and modules in hidden courses because there is no explicit visibility filter.
