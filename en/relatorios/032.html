REPORT 032

Teacher workload summary

Per-teacher summary of visible courses, students assigned relevant roles, active accounts, course completions, and average grades.

Report purpose

Per-teacher summary of visible courses, students assigned relevant roles, active accounts, course completions, and average grades.

Why use this report?

Helps estimate the number of courses and students associated with each teacher, providing administrative reference points for academic workload and course indicators.

Available filters Visualization and SQL Limitations

Available filters

There are no dynamic SQL parameters for course, teacher, student, cohort, or date range. The query considers visible courses (kbi_c.visible = 1), teacher role ID 3 assigned in a course context (contextlevel = 50), and teacher accounts that are neither deleted nor suspended and are not guest.

Student counts use role ID 5 assignments in course contexts. The completion aggregate includes timecompleted > 0, while grade averages use course-type grade items with recorded final grades.

Visualization and full original SQL

The report includes one table visualization and one SQL query, with cache and refresh settings and Prism.js syntax highlighting. The catalog does not provide a separate PostgreSQL variant.

1. Teacher workload summary · Table

Per-teacher table listing name, distinct course count, sum of students across courses, sum of accounts that are neither deleted nor suspended, sum of formal course completion records, and mean of per-course aggregated grades.

Cache: 1h · Refresh: none.

Full original SQL

SELECT kbi_u.id,
       CONCAT(kbi_u.firstname, ' ', kbi_u.lastname) as teacher,
       COUNT(DISTINCT kbi_ctx.instanceid)       as courses,
       SUM(l.learners)                      as learners,
       SUM(l1.activelearners)               as activelearners,
       SUM(cc.completed)                    as completedlearners,
       AVG(g.grade)                         as grade
FROM mdl_user kbi_u
       LEFT JOIN mdl_role_assignments kbi_ra ON kbi_ra.userid = kbi_u.id
       LEFT JOIN mdl_context kbi_ctx ON kbi_ctx.id = kbi_ra.contextid
       JOIN mdl_course kbi_c ON kbi_ctx.instanceid = kbi_c.id AND
                            kbi_c.visible = 1
       LEFT JOIN (SELECT kbi_ctx.instanceid, count(distinct kbi_ra.userid) as learners
                  FROM mdl_role_assignments kbi_ra, mdl_context kbi_ctx
                  WHERE kbi_ctx.id = kbi_ra.contextid
                    AND kbi_ctx.contextlevel = 50
                    AND kbi_ra.roleid = 5
                  GROUP BY kbi_ctx.instanceid) AS l ON l.instanceid = kbi_ctx.instanceid
       LEFT JOIN (SELECT kbi_ctx.instanceid, count(distinct kbi_ra.userid) as activelearners
                  FROM mdl_role_assignments kbi_ra, mdl_user kbi_u, mdl_context kbi_ctx
                  WHERE kbi_ctx.id = kbi_ra.contextid
                    AND kbi_ctx.contextlevel = 50
                    AND kbi_u.id = kbi_ra.userid
                    AND kbi_u.deleted = 0
                    AND kbi_u.suspended = 0
                    AND kbi_ra.roleid = 5
                  GROUP BY kbi_ctx.instanceid) AS l1 ON l1.instanceid = kbi_ctx.instanceid
       LEFT JOIN (SELECT course, count(id) as completed
                  FROM mdl_course_completions
                  WHERE timecompleted > 0
                  GROUP BY course) cc ON cc.course = kbi_ctx.instanceid
       LEFT JOIN (SELECT kbi_gi.courseid,
                         ROUND(AVG(CASE
                                     WHEN kbi_g.rawgrademax > 0 THEN (kbi_g.finalgrade / kbi_g.rawgrademax) * 100
                                     ELSE kbi_g.finalgrade END), 0) AS grade
                  FROM mdl_grade_items kbi_gi, mdl_grade_grades kbi_g
                  WHERE kbi_gi.itemtype = 'course'
                    AND kbi_g.itemid = kbi_gi.id
                    AND kbi_g.finalgrade IS NOT NULL
                  GROUP BY kbi_gi.courseid) g ON g.courseid = kbi_ctx.instanceid
WHERE kbi_ctx.contextlevel = 50
  AND kbi_ra.roleid = 3
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username != 'guest'
GROUP BY kbi_u.id, kbi_u.firstname, kbi_u.lastname

Limitations and cautions

  • Workload is approximated by course and student counts. The SQL does not calculate teaching hours, marking time, student support sessions, or contracted workload.
  • The learners and activelearners columns sum counts across courses. A student enrolled in several courses may be counted more than once.
  • The activelearners field counts accounts that are neither deleted nor suspended, not users with recent access, and does not directly verify active enrolments.
  • The completedlearners count sums course completion records and may count the same person in different courses.
  • The grade field is the mean of averages calculated per course, without necessarily weighting by student count, credits, or course hours.
  • The joins begin with role assignments. Repeated assignments for the same teacher and course can duplicate SUM aggregates, whereas the course count uses COUNT(DISTINCT ...).
  • There is no selectable period or separate PostgreSQL variant. Verify indicators before using them to allocate workload.
