REPORT 001

Online students

Shows recent student activity and platform usage: an approximate IP geolocation map, a user list, recorded time by course, and breakdowns by browser, operating system, and city or country.

What this report shows

Shows recent student activity and platform usage: an approximate IP geolocation map, a user list, recorded time by course, and breakdowns by browser, operating system, and city or country.

Why and when to use it

Helps support teams check recent presence in Moodle and identify access patterns. It can also help investigate usage concentrations, commonly used browsers, and approximate locations, without treating those indicators as evidence of actual learning.

Available filters Visualizations and SQL Limitations

Available filters

There are no dynamic SQL filters for course, user, cohort, or date range in this report. The five-minute window for the map and list, and the 30-day period for the course chart, are fixed query criteria rather than interactive selectors.

Fixed time windows apply: recent data covers five minutes, the course chart covers 30 days, and the pie charts do not apply a fixed date range in SQL.

Visualizations and SQL

This report contains 9 SQL queries across 6 visualizations: three have separate PostgreSQL and MySQL variants, and three use shared SQL. Each item provides its visualization type, purpose, cache settings, and full SQL for each variant. Expand an item to inspect its code.

1. Online students map · Map

Map showing IP addresses, locations, and geographical coordinates obtained from IP location records.

Cache: none. Refresh: 1m.

Full original PostgreSQL SQL

SELECT DISTINCT
       kbo.userid,
       kbo.lastip,
       loc.city_name,
       loc.country_name,
       loc.country_code,
       loc.latitude,
       loc.longitude
  FROM mdl_local_kopere_bi_online kbo
  JOIN mdl_local_kopere_bi_iplocation loc ON loc.id = kbo.iplocationid
 WHERE kbo.currenttime > (EXTRACT(EPOCH FROM CURRENT_TIMESTAMP)::bigint) - (5 * 60)
   AND loc.status = 1

Full original MySQL SQL

2. Online students list · Table

Table of names, cities, and countries for recently recorded users.

Cache: none. Refresh: none.

Full original PostgreSQL SQL

SELECT DISTINCT
       u.id AS u_id,
       u.firstname,
       u.lastname,
       loc.city_name,
       loc.country_name
  FROM mdl_local_kopere_bi_online kbo
  JOIN mdl_user u ON u.id = kbo.userid
  LEFT JOIN mdl_local_kopere_bi_iplocation loc ON loc.id = kbo.iplocationid
 WHERE kbo.currenttime > (EXTRACT(EPOCH FROM CURRENT_TIMESTAMP)::bigint) - (5 * 60)

3. Recorded time by course · Line chart

Line chart with distinct user counts and recorded seconds by course.

Cache: 30m. Refresh: 30m.

Full original PostgreSQL SQL

   SELECT c.fullname,
          count(DISTINCT kbo.userid) AS "lang::num_user::local_kopere_bi",
          SUM(kbo.seconds)           AS "lang::seconds::local_kopere_bi"
     FROM mdl_course c
LEFT JOIN mdl_local_kopere_bi_online kbo ON kbo.courseid = c.id
    WHERE kbo.currenttime > (EXTRACT(EPOCH FROM CURRENT_TIMESTAMP)::bigint) - (30 * 24 * 60 * 60)
 GROUP BY c.id

Full original MySQL SQL

   SELECT c.fullname,
          count(DISTINCT kbo.userid) AS 'lang::num_user::local_kopere_bi',
          SUM(kbo.seconds)           AS 'lang::seconds::local_kopere_bi'
     FROM mdl_course c
LEFT JOIN mdl_local_kopere_bi_online kbo ON kbo.courseid = c.id
    WHERE kbo.currenttime > UNIX_TIMESTAMP() - (30 * 24 * 60 * 60)
 GROUP BY c.id
4. Time by browser · Pie chart

Pie chart of accumulated seconds by browser.

Cache: 30m. Refresh: 30m.

Full original SQL

  SELECT kbo.client_name,
         SUM(kbo.seconds) as times
    FROM mdl_local_kopere_bi_online kbo
    JOIN mdl_user c ON c.id = kbo.userid
GROUP BY kbo.client_name
ORDER BY times DESC
   LIMIT 15

6. Time by city and country · Pie chart

Pie chart by city and country, limited to ten categories.

Cache: 30m. Refresh: 30m.

Full original SQL

  SELECT CONCAT(loc.city_name, '/', loc.country_name) AS country_name,
         SUM(kbo.seconds) as times
    FROM mdl_local_kopere_bi_online kbo
    JOIN mdl_user c ON c.id = kbo.userid
    JOIN mdl_local_kopere_bi_iplocation loc ON loc.id = kbo.iplocationid
GROUP BY loc.city_name, loc.country_name
ORDER BY times DESC
   LIMIT 10

Limitations and interpretation

  • Online means a record within the last five minutes for the map and list; it does not indicate a persistent connection.
  • The course access chart covers the last 30 days; the pie chart queries do not apply this time limit.
  • IP geolocation is approximate, and recorded time does not prove attention or learning.
  • The map, table, and line chart have separate MySQL and PostgreSQL queries, while the pie charts use shared SQL.
