REPORT 066

Quiz attempt summary by quiz

Per-quiz summary for the selected course with question slot counts, configuration dates, attempt counts, total duration, and average percentage scores.

Report purpose

Per-quiz summary for the selected course with question slot counts, configuration dates, attempt counts, total duration, and average percentage scores.

Why use this report?

Helps identify quizzes with the greatest volume of attempts and compare general usage and scoring indicators, supporting further analysis of quiz settings and assessment results.

Available filters Visualization and SQL Limitations

Available filters

The dynamic filter is Course, linked to :courseid and used once in kbi_q.course = :courseid.

The query requires a visible course and a positive quiz ID. It does not require a visible quiz module, exclude preview attempts, filter for finished attempts, or restrict users, roles, enrolments, or date ranges.

Visualization and full original SQL

One table visualization contains the full original SQL query, cache and refresh settings, and Prism.js syntax highlighting. No separate PostgreSQL definition is available in the catalog.

1. Quiz attempt summary by quiz · Table

The table lists each quiz's ID, name, course, number of slots in mdl_quiz_slots, modification date, configured opening and closing dates, average percentage score across attempts, distinct attempt count, and total elapsed duration in seconds.

Cache: 1h · Refresh: none.

Full original SQL

SELECT kbi_q.id,
       kbi_q.name,
       kbi_q.course,
       kbi_c.fullname,
       MAX(ql.questions)                       AS questions,
       kbi_q.timemodified,
       kbi_q.timeopen,
       kbi_q.timeclose,
       avg((kbi_qa.sumgrades / kbi_q.sumgrades) * 100) AS grade,
       count(distinct(kbi_qa.id))                  AS attempts,
       sum(kbi_qa.timefinish - kbi_qa.timestart)       AS duration
FROM mdl_quiz kbi_q
       JOIN mdl_course kbi_c ON kbi_c.id = kbi_q.course
       LEFT JOIN mdl_quiz_attempts kbi_qa ON kbi_qa.quiz = kbi_q.id
       LEFT JOIN (SELECT quizid, count(*) questions FROM mdl_quiz_slots GROUP BY quizid) ql ON ql.quizid = kbi_q.id
       LEFT JOIN mdl_modules kbi_m ON kbi_m.name = 'quiz'
       LEFT JOIN mdl_course_modules kbi_cm ON kbi_cm.module = kbi_m.id AND kbi_cm.course = kbi_c.id AND kbi_cm.instance = kbi_q.id
WHERE kbi_q.id > 0
  AND kbi_q.course = :courseid
  AND kbi_c.visible = 1
GROUP BY kbi_q.id, kbi_c.id
ORDER BY kbi_q.name

Limitations and cautions

  • The questions field counts slots in mdl_quiz_slots, not necessarily unique questions. A quiz may reuse questions or have slots that do not correspond one-to-one with individual questions.
  • The optional join includes quizzes with no attempts. In such cases, counts and aggregates may be zero or NULL depending on the function.
  • The attempt count uses COUNT(DISTINCT kbi_qa.id), which is not the number of distinct students who attempted the quiz.
  • The average grade derives from kbi_qa.sumgrades / kbi_q.sumgrades, without protection against a zero maximum score or a requirement for finished attempts, and does not necessarily represent the consolidated final grade.
  • The duration field sums timefinish - timestart without filtering ongoing attempts. A zero finish time may introduce negative durations.
  • The query requires the course to be visible, but the main filter does not include kbi_cm.visible = 1. Hidden quizzes in the course may appear.
  • The timeopen and timeclose dates are configured quiz availability settings, not the participants' first and last access dates.
  • The SQL has no monitoring period, does not distinguish preview attempts, and does not provide a separate PostgreSQL variant.
