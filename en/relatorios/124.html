REPORT 124

Performance by grading criterion

Assignment rubric and marking guide criteria results, including distinct assessments, average scores, and percentages.

Report purpose

Table by course, assignment module, grading method, and criterion, showing the activity name, criterion identifier, number of assessed instances, average points awarded, maximum points, and calculated average percentage. Results are sorted by course, module, method, and criterion, with a maximum of 500 rows.

Why use this report?

Compare performance across criteria used in assignments graded with marking guides or rubrics, examining average criterion scores, counts of distinct assessments, and differences between criteria.

Available filters Visualization and SQL Calculation criteria Limitations

Available filters

There are no dynamic SQL parameters for course, activity, teacher, student, criterion, grading method, or date range. The report aggregates records associated with grading areas area.component = 'mod_assign' in module contexts cx.contextlevel = 70, with inst.status = 1.

The two methods are guide (marking guide) and rubric (rubric). Their sources are combined with UNION ALL. The SQL limits the result to 500 criterion groups without explicitly filtering hidden courses, hidden activities, or any date range.

Visualization and full original SQL

One table visualization contains the full original SQL, cache, and refresh settings, highlighted with Prism.js. No separate PostgreSQL variant was found in master; no nonexistent query has been added.

1. Performance by grading criterion · Table

Table by course, assignment module, grading method, and criterion, showing the activity name, criterion identifier, number of distinct assessed instances, mean score, maximum possible score, and calculated average percentage. Results are ordered by course, module, method, and criterion, up to 500 rows.

Cache: 1h · Refresh: none.

Full original SQL

SELECT CONCAT(src.moduleid, '-', src.method, '-', src.criterionid) AS id,
       c.id AS courseid, c.fullname AS course, src.moduleid, assignment.name AS activity_name, src.method, src.criterionid,
       MAX(src.criterion) AS criterion,
       COUNT(DISTINCT src.instanceid) AS assessments, ROUND(AVG(src.score), 2) AS average_score,
       MAX(src.maxscore) AS maximum_score,
       CASE WHEN MAX(src.maxscore) > 0 THEN ROUND(100.0 * AVG(src.score) / MAX(src.maxscore), 2)
            ELSE NULL END AS average_percent
  FROM (
        SELECT cx.instanceid AS moduleid, 'guide' AS method, crit.id AS criterionid,
               crit.shortname AS criterion, fill.score AS score, crit.maxscore AS maxscore, inst.id AS instanceid
          FROM mdl_gradingform_guide_fillings fill
          JOIN mdl_gradingform_guide_criteria crit ON crit.id = fill.criterionid
          JOIN mdl_grading_instances inst ON inst.id = fill.instanceid AND inst.status = 1
          JOIN mdl_grading_definitions def ON def.id = inst.definitionid AND def.method = 'guide'
          JOIN mdl_grading_areas area ON area.id = def.areaid AND area.component = 'mod_assign'
          JOIN mdl_context cx ON cx.id = area.contextid AND cx.contextlevel = 70
        UNION ALL
        SELECT cx.instanceid AS moduleid, 'rubric' AS method, crit.id AS criterionid,
               crit.description AS criterion, level.score AS score,
               (SELECT MAX(lev2.score) FROM mdl_gradingform_rubric_levels lev2
                 WHERE lev2.criterionid = crit.id) AS maxscore, inst.id AS instanceid
          FROM mdl_gradingform_rubric_fillings fill
          JOIN mdl_gradingform_rubric_criteria crit ON crit.id = fill.criterionid
          JOIN mdl_gradingform_rubric_levels level ON level.id = fill.levelid
          JOIN mdl_grading_instances inst ON inst.id = fill.instanceid AND inst.status = 1
          JOIN mdl_grading_definitions def ON def.id = inst.definitionid AND def.method = 'rubric'
          JOIN mdl_grading_areas area ON area.id = def.areaid AND area.component = 'mod_assign'
          JOIN mdl_context cx ON cx.id = area.contextid AND cx.contextlevel = 70
       ) src
  JOIN mdl_course_modules cm ON cm.id = src.moduleid
  JOIN mdl_modules m ON m.id = cm.module AND m.name = 'assign'
  JOIN mdl_assign assignment ON assignment.id = cm.instance
  JOIN mdl_course c ON c.id = cm.course
 GROUP BY c.id, c.fullname, src.moduleid, assignment.name, src.method, src.criterionid
 ORDER BY c.fullname, src.moduleid, src.method, criterion
 LIMIT 500

Calculation criteria and behavior

For marking guides, criterion points come from mdl_gradingform_guide_fillings.score, names from guide_criteria.shortname, and maxima from guide_criteria.maxscore. For rubrics, the selected score comes from mdl_gradingform_rubric_levels.score, the description from rubric_criteria.description, and the maximum from the highest level score of that rubric.

Aggregation uses COUNT(DISTINCT src.instanceid) for distinct assessments and AVG(src.score) for the mean of present records. The percentage is 100.0 * AVG(src.score) / MAX(src.maxscore) when the maximum is positive; otherwise it returns NULL. The query combines method-and-criterion occurrences in status-1 records and only associates modules of type assign.

Limitations and cautions

  • The report finds only instances where inst.status = 1. Missing assessments, unfilled records, and records in other states do not contribute to the averages.
  • The assessments field counts distinct grading instances, not necessarily distinct students. A student may have more than one assessment, and history may be absent depending on configuration.
  • Averages and percentages depend on each criterion's scale and range. Criteria with different scales should not be compared solely by raw mean values.
  • The calculation uses MAX(maxscore) as its denominator while averaging recorded scores. Historical changes to criteria or levels may mean the percentage does not reconstruct the scale used for every assessment.
  • Rubric criterion labels may contain markup. Display stored content according to Moodle's content safety and escaping rules.
  • Without an explicit reporting-period filter, the table aggregates the grading records currently retained and displays only the first 500 criterion groups in the specified order.
  • The original SQL does not check course or module visibility and does not identify individual learners in this aggregate table. Restrict publication of academic metrics under institutional policy.

The SQL was reproduced verbatim from the original JSON definition in master. No queries were executed on Moodle during this documentation work. Before institutional use, validate database compatibility, interpretation of the data, and access permissions.
