REPORT 022

Platform usage summary by user

Table of users with recorded access, average course grades, system-context roles, course counts, and tracked time and visits recorded by Kopere BI.

Report purpose

Table of users with recorded access, average course grades, system-context roles, course counts, and tracked time and visits recorded by Kopere BI.

Why use this report?

Helps administrators review profile information, academic associations, and usage measures in one table, identifying accounts that may require further investigation or follow-up.

Actual filters Visualization and SQL Limitations

Available filters

There are no dynamic SQL parameters for course, user, cohort, or date range. Included accounts have id > 0, are neither deleted nor suspended, and are not guest.

Average grades and course counts use role ID 5 assignments in course contexts (contextlevel = 50), visible courses, and grade items of type course. Roles in the roles column come from system-context assignments (contextlevel = 10). Time and visits have no explicit time-window restriction.

Visualization and full original SQL

The report contains one table visualization and two SQL queries, with cache, refresh settings, and Prism.js syntax highlighting. MySQL and PostgreSQL variants are displayed in separate panels within the same block.

1. Platform usage summary by user · Table

The table includes the user's name, email, last access, and account creation date, average course grade percentage, aggregated course count, system-context roles, and total recorded time and visits. MySQL and PostgreSQL produce the same visualization using different aggregation and rounding functions.

Cache: 1h · Refresh: none.

Full original MySQL SQL

SELECT kbi_u.id,
       kbi_u.lastaccess,
       kbi_u.firstname,
       kbi_u.lastname,
       kbi_u.email,
       grd.grade,
       sls.roles,
       kbi_u.timecreated,
       grd.courses,
       lit.timespend AS timespend,
       lit.visits    AS visits
FROM mdl_user kbi_u
       LEFT JOIN (SELECT kbi_ra.userid,
                         ROUND(AVG(CASE
                                     WHEN kbi_g.rawgrademax > 0 THEN (kbi_g.finalgrade / kbi_g.rawgrademax) * 100
                                     ELSE kbi_g.finalgrade END), 0) AS grade,
                         COUNT(DISTINCT kbi_ctx.instanceid)         as courses
                  FROM mdl_role_assignments kbi_ra
                         JOIN mdl_context kbi_ctx ON kbi_ctx.id = kbi_ra.contextid AND
                                                    kbi_ctx.contextlevel = 50
                         JOIN mdl_user kbi_u ON kbi_u.id = kbi_ra.userid
                         LEFT JOIN mdl_grade_items kbi_gi ON kbi_gi.courseid = kbi_ctx.instanceid AND
                                                         kbi_gi.itemtype = 'course'
                         LEFT JOIN mdl_grade_grades kbi_g ON kbi_g.itemid = kbi_gi.id AND
                                                         kbi_g.userid = kbi_ra.userid AND
                                                         kbi_g.finalgrade IS NOT NULL
                         JOIN mdl_course kbi_c ON kbi_ctx.instanceid = kbi_c.id AND
                                              kbi_c.visible = 1
                  WHERE kbi_gi.itemtype = 'course'
                    AND kbi_ra.roleid = 5
                  GROUP BY kbi_ra.userid) grd ON grd.userid = kbi_u.id
       LEFT JOIN (SELECT kbi_ra.userid, GROUP_CONCAT(DISTINCT (kbi_r.shortname) SEPARATOR ',') AS roles
                  FROM mdl_context kbi_ctx
                         JOIN mdl_role_assignments kbi_ra ON kbi_ra.contextid = kbi_ctx.id
                         JOIN mdl_role kbi_r ON kbi_ra.roleid = kbi_r.id
                  WHERE kbi_ctx.contextlevel = 10
                  GROUP BY kbi_ra.userid) sls ON sls.userid = kbi_u.id
       LEFT JOIN (SELECT kbi_lit.userid, SUM(kbi_lil.timespend) as timespend, SUM(kbi_lil.visits) as visits
                  FROM mdl_local_kopere_bi_tracking kbi_lit
                         JOIN mdl_local_kopere_bi_track_log kbi_lil ON kbi_lil.trackid = kbi_lit.id
                  WHERE kbi_lil.id > 0
                  GROUP BY kbi_lit.userid) lit ON lit.userid = kbi_u.id
WHERE kbi_u.id > 0
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username != 'guest'

Limitations and cautions

  • The aggregated course count is linked to role ID 5 assignments and the presence of grade items of type course; it does not necessarily include all of a user's enrolments.
  • The roles column includes system-context assignments, not necessarily every role held by the user in each course.
  • The grade average depends on available records and is not weighted by credits, contact hours, or enrolment.
  • Time and visit totals come from mdl_local_kopere_bi_tracking and mdl_local_kopere_bi_track_log and depend on the plugin's collection and retention.
  • Users without grades, system roles, or tracking data may have empty columns because of optional joins.
  • The table contains personal information. Restrict access, especially before exporting data. Validate MySQL and PostgreSQL variants against the corresponding database.
