REPORT 089

Quiz scores by attempt

Consolidates scores per quiz attempt, comparing raw marks, calculated percentages, scaled quiz grades, final gradebook grades, and question grading-state counts.

Report purpose

Consolidates scores per quiz attempt, comparing raw marks, calculated percentages, scaled quiz grades, final gradebook grades, and question grading-state counts.

Why use this report?

Helps teachers and administrators investigate differences between attempt scores, calculated grades, and gradebook grades, while reviewing how question grading states are distributed.

Available filters Visualization and SQL Limitations

Available filters

There are no dynamic SQL parameters for selecting course, quiz, student, attempt, or reporting period in either the MySQL or PostgreSQL variant.

Fixed filters require kbi_qa.preview = 0, a visible course and module, and a user who is not deleted, suspended, or named guest. For each question, the SQL uses the step with the highest sequencenumber. The query does not require completed attempts, active enrolment, or a student role.

Visualization and full original SQL

One table visualization includes two complete original SQL queries, cache and refresh settings, and Prism.js syntax highlighting. Equivalent MySQL and PostgreSQL variants appear in separate panels.

1. Quiz scores by attempt · Table

The per-attempt table includes associated grades, course, quiz, module, user, attempt number, dates and state, question count, sum of maximum question marks, sum of fraction-based marks, raw attempt score, maximum score, percentage, scaled grade, configured maximum grade, passing mark, final gradebook grade, and counts of fully correct, partially correct, and incorrect question states.

Cache: 1h · Refresh: none.

Full original MySQL SQL

SELECT kbi_qa.id                                                           AS id,
       kbi_c.id                                                            AS courseid,
       kbi_c.fullname                                                      AS course,
       kbi_cm.id                                                           AS cmid,
       kbi_qz.id                                                           AS quizid,
       kbi_qz.name                                                         AS quiz_name,
       kbi_u.id                                                            AS userid,
       kbi_u.firstname,
       kbi_u.lastname,
       kbi_u.email,
       kbi_qa.attempt,
       kbi_qa.timestart,
       kbi_qa.timefinish,
       kbi_qa.state                                                        AS attempt_state,
       COUNT(DISTINCT kbi_qatt.id)                                         AS questions,
       SUM(kbi_qatt.maxmark)                                               AS question_maxmark,
       ROUND(SUM(kbi_qatt.maxmark * COALESCE(kbi_qas.fraction, 0)), 2)     AS total_question_score,
       ROUND(kbi_qa.sumgrades, 2)                                          AS rawgrade,
       kbi_qz.sumgrades                                                    AS quiz_raw_max,
       ROUND(CASE WHEN kbi_qz.sumgrades > 0 THEN kbi_qa.sumgrades * 100 / kbi_qz.sumgrades ELSE NULL END, 2) AS score_percent,
       ROUND(CASE WHEN kbi_qz.sumgrades > 0 THEN kbi_qa.sumgrades * kbi_qz.grade / kbi_qz.sumgrades ELSE NULL END, 2) AS finalgrade,
       kbi_qz.grade                                                        AS grademax,
       kbi_gi.gradepass,
       kbi_gg.finalgrade                                                   AS gradebook_finalgrade,
       SUM(CASE WHEN kbi_qas.state = 'gradedright' THEN 1 ELSE 0 END)      AS correct_answers,
       SUM(CASE WHEN kbi_qas.state = 'gradedpartial' THEN 1 ELSE 0 END)    AS partial_answers,
       SUM(CASE WHEN kbi_qas.state = 'gradedwrong' THEN 1 ELSE 0 END)      AS wrong_answers
FROM mdl_quiz_attempts kbi_qa
       JOIN mdl_quiz kbi_qz ON kbi_qz.id = kbi_qa.quiz
       JOIN mdl_course kbi_c ON kbi_c.id = kbi_qz.course
       JOIN mdl_user kbi_u ON kbi_u.id = kbi_qa.userid
       JOIN mdl_question_attempts kbi_qatt ON kbi_qatt.questionusageid = kbi_qa.uniqueid
       LEFT JOIN mdl_question_attempt_steps kbi_qas ON kbi_qas.questionattemptid = kbi_qatt.id
             AND kbi_qas.sequencenumber = (
                 SELECT MAX(kbi_qas2.sequencenumber)
                 FROM mdl_question_attempt_steps kbi_qas2
                 WHERE kbi_qas2.questionattemptid = kbi_qatt.id
             )
       JOIN mdl_modules kbi_m ON kbi_m.name = 'quiz'
       JOIN mdl_course_modules kbi_cm ON kbi_cm.course = kbi_c.id AND kbi_cm.module = kbi_m.id AND kbi_cm.instance = kbi_qz.id
       LEFT JOIN mdl_grade_items kbi_gi ON kbi_gi.itemmodule = 'quiz' AND kbi_gi.iteminstance = kbi_qz.id AND kbi_gi.courseid = kbi_c.id
       LEFT JOIN mdl_grade_grades kbi_gg ON kbi_gg.itemid = kbi_gi.id AND kbi_gg.userid = kbi_u.id
WHERE kbi_qa.preview = 0
  AND kbi_c.visible = 1
  AND kbi_cm.visible = 1
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username <> 'guest'
GROUP BY kbi_qa.id, kbi_c.id, kbi_cm.id, kbi_qz.id, kbi_u.id, kbi_gi.gradepass, kbi_gg.finalgrade
ORDER BY kbi_c.fullname, kbi_qz.name, kbi_u.lastname, kbi_u.firstname, kbi_qa.attempt

Limitations and cautions

  • The query does not require kbi_qa.state = 'finished'. Scores for unfinished attempts may be NULL, incomplete, or subject to change.
  • The total_question_score field sums question maximum marks multiplied by fractions from the latest grading steps, substituting zero for missing fractions. It may differ from rawgrade, which comes from mdl_quiz_attempts.sumgrades.
  • The score_percent field requires the quiz maximum sumgrades to be positive. Otherwise it is NULL; the same protection applies when calculating finalgrade.
  • The finalgrade field is calculated from the attempt score and the scale configured in mdl_quiz.grade. By contrast, gradebook_finalgrade comes from the gradebook and may use a different aggregation policy across attempts, so the same value may appear on multiple rows for one user.
  • The correct_answers, partial_answers, and wrong_answers counts rely exclusively on final states gradedright, gradedpartial, and gradedwrong. Questions in other states are not counted in these three totals.
  • The questions count uses distinct question-attempt IDs. It should not be confused with unique questions in the question bank or with configured quiz slot counts.
  • The SQL groups results by attempt and related gradebook records. Multiple associated grade items or records may introduce extra rows or alter aggregate totals.
  • There is no active-enrolment or student-role check and no dynamic course filter. Personal data and grades require controlled access and exports.
  • MySQL and PostgreSQL variants differ in explicit numeric conversions used for rounding, without changing the intended indicators.
