REPORT 062

Quiz question structure

Inventory of question slots in quizzes from visible courses, showing question bank entries, selected versions, question properties, and tags.

Report purpose

Inventory of question slots in quizzes from visible courses, showing question bank entries, selected versions, question properties, and tags.

Why use this report?

Helps audit quiz organization, check question slots and pages, identify question types and versions, and locate incomplete references requiring review.

Available filters Visualization and SQL Limitations

Available filters

There is no dynamic SQL filter for course, quiz, question category, tag, version, or date. The query covers quizzes in visible courses and modules (kbi_c.visible = 1 and kbi_cm.visible = 1).

For each slot, the question reference uses component = 'mod_quiz' and questionarea = 'slot'. The selected version is either explicitly referenced or, when kbi_qr.version IS NULL, the highest version number of the corresponding question bank entry.

Visualization and full original SQL

One table visualization includes two SQL queries, cache and refresh settings, and Prism.js syntax highlighting. The MySQL and PostgreSQL variants appear in separate panels within a single block.

1. Quiz question structure · Table

The table contains one row per question position (quiz slot), with course, quiz, CMID, slot number and page, maximum mark, question bank entry, version, question ID and name, type, default mark, length, version status, and tags.

Cache: 1h · Refresh: none.

Full original MySQL SQL

SELECT kbi_slot.id                AS id,
       kbi_c.id                   AS courseid,
       kbi_c.fullname             AS course,
       kbi_cm.id                  AS cmid,
       kbi_qz.id                  AS quizid,
       kbi_qz.name                AS quiz_name,
       kbi_slot.slot,
       kbi_slot.page              AS slot_page,
       kbi_slot.maxmark,
       kbi_qbe.id                 AS questionbankentryid,
       kbi_qv.version,
       kbi_q.id                   AS questionid,
       kbi_q.name                 AS question_name,
       kbi_q.qtype,
       kbi_q.defaultmark,
       kbi_q.length,
       kbi_qv.status              AS question_status,
       kbi_tags.tags              AS question_tags
FROM mdl_quiz kbi_qz
       JOIN mdl_course kbi_c ON kbi_c.id = kbi_qz.course
       JOIN mdl_modules kbi_m ON kbi_m.name = 'quiz'
       JOIN mdl_course_modules kbi_cm ON kbi_cm.course = kbi_c.id AND kbi_cm.module = kbi_m.id AND kbi_cm.instance = kbi_qz.id
       JOIN mdl_quiz_slots kbi_slot ON kbi_slot.quizid = kbi_qz.id
       LEFT JOIN mdl_question_references kbi_qr ON kbi_qr.component = 'mod_quiz'
             AND kbi_qr.questionarea = 'slot'
             AND kbi_qr.itemid = kbi_slot.id
       LEFT JOIN mdl_question_bank_entries kbi_qbe ON kbi_qbe.id = kbi_qr.questionbankentryid
       LEFT JOIN mdl_question_versions kbi_qv ON kbi_qv.questionbankentryid = kbi_qbe.id
             AND (
                 kbi_qv.version = kbi_qr.version
                 OR (kbi_qr.version IS NULL AND kbi_qv.version = (
                     SELECT MAX(kbi_qv2.version)
                     FROM mdl_question_versions kbi_qv2
                     WHERE kbi_qv2.questionbankentryid = kbi_qbe.id
                 ))
             )
       LEFT JOIN mdl_question kbi_q ON kbi_q.id = kbi_qv.questionid
       LEFT JOIN (
             SELECT kbi_ti.itemid,
                    GROUP_CONCAT(DISTINCT kbi_t.rawname ORDER BY kbi_t.rawname SEPARATOR ', ') AS tags
             FROM mdl_tag_instance kbi_ti
                    JOIN mdl_tag kbi_t ON kbi_t.id = kbi_ti.tagid
             WHERE kbi_ti.itemtype = 'question'
             GROUP BY kbi_ti.itemid
       ) kbi_tags ON kbi_tags.itemid = kbi_q.id
WHERE kbi_c.visible = 1
  AND kbi_cm.visible = 1
ORDER BY kbi_c.fullname, kbi_qz.name, kbi_slot.slot

Full original PostgreSQL SQL

SELECT kbi_slot.id                AS id,
       kbi_c.id                   AS courseid,
       kbi_c.fullname             AS course,
       kbi_cm.id                  AS cmid,
       kbi_qz.id                  AS quizid,
       kbi_qz.name                AS quiz_name,
       kbi_slot.slot,
       kbi_slot.page              AS slot_page,
       kbi_slot.maxmark,
       kbi_qbe.id                 AS questionbankentryid,
       kbi_qv.version,
       kbi_q.id                   AS questionid,
       kbi_q.name                 AS question_name,
       kbi_q.qtype,
       kbi_q.defaultmark,
       kbi_q.length,
       kbi_qv.status              AS question_status,
       kbi_tags.tags              AS question_tags
FROM mdl_quiz kbi_qz
       JOIN mdl_course kbi_c ON kbi_c.id = kbi_qz.course
       JOIN mdl_modules kbi_m ON kbi_m.name = 'quiz'
       JOIN mdl_course_modules kbi_cm ON kbi_cm.course = kbi_c.id AND kbi_cm.module = kbi_m.id AND kbi_cm.instance = kbi_qz.id
       JOIN mdl_quiz_slots kbi_slot ON kbi_slot.quizid = kbi_qz.id
       LEFT JOIN mdl_question_references kbi_qr ON kbi_qr.component = 'mod_quiz'
             AND kbi_qr.questionarea = 'slot'
             AND kbi_qr.itemid = kbi_slot.id
       LEFT JOIN mdl_question_bank_entries kbi_qbe ON kbi_qbe.id = kbi_qr.questionbankentryid
       LEFT JOIN mdl_question_versions kbi_qv ON kbi_qv.questionbankentryid = kbi_qbe.id
             AND(
                 kbi_qv.version = kbi_qr.version
                 OR(kbi_qr.version IS NULL AND kbi_qv.version = (
                     SELECT MAX(kbi_qv2.version)
                     FROM mdl_question_versions kbi_qv2
                     WHERE kbi_qv2.questionbankentryid = kbi_qbe.id
                 ))
             )
       LEFT JOIN mdl_question kbi_q ON kbi_q.id = kbi_qv.questionid
       LEFT JOIN(
             SELECT kbi_ti.itemid,
                    STRING_AGG(DISTINCT (kbi_t.rawname)::text, ', ' ORDER BY (kbi_t.rawname)::text) AS tags
             FROM mdl_tag_instance kbi_ti
                    JOIN mdl_tag kbi_t ON kbi_t.id = kbi_ti.tagid
             WHERE kbi_ti.itemtype = 'question'
             GROUP BY kbi_ti.itemid
       ) kbi_tags ON kbi_tags.itemid = kbi_q.id
WHERE kbi_c.visible = 1
  AND kbi_cm.visible = 1
ORDER BY kbi_c.fullname, kbi_qz.name, kbi_slot.slot

Limitations and cautions

  • The query uses optional joins for references, question bank entries, versions, questions, and tags. Question slots without resolved references may therefore appear with empty question details.
  • When a reference does not specify a version, the SQL selects the highest version number for that entry. This selection does not check whether the version has ready status or is the pedagogically intended version.
  • The question_status field only displays the selected version's status. Questions that are not ready are not excluded.
  • The inventory does not report answers, choices, grading criteria, attempts, student performance, or question-writing quality.
  • The tag list aggregates question-related names but does not guarantee that question bank categories are fully or correctly organized.
  • The SQL includes only visible modules and courses, but does not check individual access restrictions, availability conditions, or each student's viewing permissions.
  • MySQL and PostgreSQL use different tag aggregation functions. There is no date filter, so the report reflects the structure available when the query is run.
