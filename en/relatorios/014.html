REPORT 014

Login statistics

Shows account details, access dates, and accumulated time recorded by Kopere BI for the platform, courses, and activities.

Report purpose

Shows account details, access dates, and accumulated time recorded by Kopere BI for the platform, courses, and activities.

Why use this report?

Helps administrators locate user profiles and inspect recorded tracking patterns, comparing time attributed to general site use, courses, and activities.

Actual filters Visualization and SQL Limitations

Available filters

This definition has no dynamic course, user, cohort, or date-range SQL parameters, so it does not apply selectors for those dimensions.

Fixed conditions require an account that is neither deleted nor suspended, an ID greater than 0, and a username other than guest. Course-level calculations use courseid > 0; activity-level calculations use page = 'module'.

1. Login statistics · Table

Per-user table showing name, email address, telephone numbers, institution, department, address, location, account creation date, first and last access, and the sums timespend_site, timespend_courses, and timespend_activities from the Kopere BI tracking table.

Cache: 1h · Refresh: none.

Full original SQL

SELECT kbi_u.id,
       kbi_u.firstname,
       kbi_u.lastname,
       kbi_u.email,
       kbi_u.phone1,
       kbi_u.phone2,
       kbi_u.institution,
       kbi_u.department,
       kbi_u.address,
       kbi_u.city,
       kbi_u.country,
       kbi_u.timecreated,
       kbi_u.firstaccess,
       kbi_u.lastaccess,
       lit1.timespend_site,
       lit2.timespend_courses,
       lit3.timespend_activities
FROM mdl_user kbi_u
       LEFT JOIN (SELECT kbi_t.userid, SUM(timespend) AS timespend_site
                  FROM mdl_local_kopere_bi_tracking kbi_t
                  WHERE kbi_t.id > 0
                  GROUP BY kbi_t.userid) lit1 ON lit1.userid = kbi_u.id
       LEFT JOIN (SELECT kbi_t.userid, SUM(timespend) AS timespend_courses
                  FROM mdl_local_kopere_bi_tracking kbi_t
                  WHERE kbi_t.courseid > 0
                  GROUP BY kbi_t.userid) lit2 ON lit2.userid = kbi_u.id
       LEFT JOIN (SELECT kbi_t.userid, SUM(timespend) AS timespend_activities
                  FROM mdl_local_kopere_bi_tracking kbi_t
                  WHERE kbi_t.page = 'module'
                  GROUP BY kbi_t.userid) lit3 ON lit3.userid = kbi_u.id
WHERE kbi_u.id > 0
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username != 'guest'

Limitations and cautions

  • Despite the title, the SQL does not calculate the number of logins or sessions. It reads user profile fields and sums tracked time stored in mdl_local_kopere_bi_tracking.
  • Time spent on the site, in courses, and in activities may represent overlapping sets; do not add them as independent categories without reviewing the meaning of the records.
  • There is no time window in the SQL. The totals therefore reflect the history available in the tracking table, subject to plugin maintenance and data collection.
  • The report contains sensitive address, telephone, and institution fields; control the viewing and exporting of personal information.
  • Missing time values may indicate an absence of records in the source rather than a lack of participation or access.
