REPORT 067

Quiz grade details by student

Displays quizzes and recorded attempts for users with the student role in the selected course, including dates, duration, state, percentage score, and module tags.

Report purpose

Displays quizzes and recorded attempts for users with the student role in the selected course, including dates, duration, state, percentage score, and module tags.

Why use this report?

Allows teachers to examine quiz attempts per student, compare recorded scores, and review attempt start and finish times, states, and associated module tags.

Available filters Visualization and SQL Limitations

Available filters

The dynamic SQL filter is Course, represented by :courseid once in the MySQL query and once in the PostgreSQL query, in the condition ra.instanceid = :courseid.

Fixed conditions include student role ID 5 assigned in a course context (contextlevel = 50), a visible course, and users who are neither deleted nor suspended and are not guest. There is no filter for attempt state, date, active enrolment, or module visibility.

Visualization and full original SQL

One table visualization includes two complete original SQL queries, cache and refresh settings, and Prism.js syntax highlighting. Equivalent MySQL and PostgreSQL variants appear in separate panels within the same visualization.

1. Quiz grade details by student · Table

The table lists each student, quiz, and attempt (or an entry without an attempt), with course and quiz names, student name and email, configured quiz close date, attempt start and finish times, state, calculated duration, percentage score, module tags, and an empty cohort field.

Cache: 1h · Refresh: none.

Full original MySQL SQL

SELECT kbi_qa.id,
       kbi_q.name,
       kbi_u.email,
       kbi_q.course,
       kbi_q.timeclose,
       kbi_c.fullname,
       kbi_qa.timestart,
       kbi_qa.timefinish,
       kbi_qa.state,
       (kbi_qa.timefinish - kbi_qa.timestart)                  as duration,
       (kbi_qa.sumgrades / MAX(kbi_q.sumgrades) * 100)         as grade,
       kbi_u.firstname,
       kbi_u.lastname,
       GROUP_CONCAT(DISTINCT kbi_t.rawname SEPARATOR ', ') as tags,
       ''                                              AS cohortname
FROM (SELECT kbi_ctx.instanceid, kbi_ra1.userid
      FROM mdl_context kbi_ctx
             JOIN mdl_role_assignments kbi_ra1 ON kbi_ra1.contextid = kbi_ctx.id AND kbi_ra1.roleid = 5
      WHERE kbi_ctx.contextlevel = 50
      GROUP BY kbi_ctx.instanceid, kbi_ra1.userid) ra
       JOIN mdl_modules kbi_m ON kbi_m.name = 'quiz'
       JOIN mdl_course_modules kbi_cm ON kbi_cm.course = ra.instanceid AND kbi_cm.module = kbi_m.id
       JOIN mdl_quiz kbi_q ON kbi_q.id = kbi_cm.instance
       JOIN mdl_user kbi_u ON kbi_u.id = ra.userid
       JOIN mdl_course kbi_c ON kbi_c.id = ra.instanceid
       LEFT JOIN mdl_quiz_attempts kbi_qa ON kbi_qa.quiz = kbi_q.id AND kbi_qa.userid = ra.userid
       LEFT JOIN mdl_tag_instance kbi_ti ON kbi_ti.itemtype = 'course_modules' AND kbi_ti.itemid = kbi_cm.id
       LEFT JOIN mdl_tag kbi_t ON kbi_t.id = kbi_ti.tagid
WHERE ra.instanceid > 0
  AND ra.instanceid = :courseid
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username != 'guest'
  AND kbi_c.visible = 1
GROUP BY kbi_u.id, kbi_q.id, kbi_c.id, kbi_qa.id

Full original PostgreSQL SQL

SELECT kbi_qa.id,
       kbi_q.name,
       kbi_u.email,
       kbi_q.course,
       kbi_q.timeclose,
       kbi_c.fullname,
       kbi_qa.timestart,
       kbi_qa.timefinish,
       kbi_qa.state,
       (kbi_qa.timefinish - kbi_qa.timestart)                  as duration,
       (kbi_qa.sumgrades / MAX(kbi_q.sumgrades) * 100)         as grade,
       kbi_u.firstname,
       kbi_u.lastname,
       STRING_AGG(DISTINCT (kbi_t.rawname)::text, ', ') as tags,
       ''                                              AS cohortname
FROM(SELECT kbi_ctx.instanceid, kbi_ra1.userid
      FROM mdl_context kbi_ctx
             JOIN mdl_role_assignments kbi_ra1 ON kbi_ra1.contextid = kbi_ctx.id AND kbi_ra1.roleid = 5
      WHERE kbi_ctx.contextlevel = 50
      GROUP BY kbi_ctx.instanceid, kbi_ra1.userid) ra
       JOIN mdl_modules kbi_m ON kbi_m.name = 'quiz'
       JOIN mdl_course_modules kbi_cm ON kbi_cm.course = ra.instanceid AND kbi_cm.module = kbi_m.id
       JOIN mdl_quiz kbi_q ON kbi_q.id = kbi_cm.instance
       JOIN mdl_user kbi_u ON kbi_u.id = ra.userid
       JOIN mdl_course kbi_c ON kbi_c.id = ra.instanceid
       LEFT JOIN mdl_quiz_attempts kbi_qa ON kbi_qa.quiz = kbi_q.id AND kbi_qa.userid = ra.userid
       LEFT JOIN mdl_tag_instance kbi_ti ON kbi_ti.itemtype = 'course_modules' AND kbi_ti.itemid = kbi_cm.id
       LEFT JOIN mdl_tag kbi_t ON kbi_t.id = kbi_ti.tagid
WHERE ra.instanceid > 0
  AND ra.instanceid = :courseid
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username != 'guest'
  AND kbi_c.visible = 1
GROUP BY kbi_u.id, kbi_q.id, kbi_c.id, kbi_qa.id

Limitations and cautions

  • The query uses role ID 5 assignments but does not verify active enrolment or enrolment validity. Users with the assigned role but without a current enrolment may still appear.
  • Attempts are joined with LEFT JOIN, so students without attempts may still produce a quiz row with NULL attempt data.
  • The SQL does not restrict kbi_qa.preview or kbi_qa.state; preview and unfinished attempts may appear.
  • The grade field divides an attempt score by the quiz maximum score. No NULLIF protects division when sumgrades = 0.
  • Duration is simply timefinish - timestart, without establishing that an attempt finished; ongoing attempts may produce negative or inconsistent durations.
  • The cohortname field is a constant empty string in the SQL. Despite its name, it does not indicate cohort membership.
  • The SQL requires a visible course but does not apply kbi_cm.visible = 1. Hidden quizzes may appear when a course role assignment exists.
  • Tags are associated with the quiz module and aggregated into text. The MySQL and PostgreSQL variants use different aggregation functions. Since names, email addresses, and grades are included, enforce access permissions.
