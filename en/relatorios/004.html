REPORT 004

Enrolment statistics

A table shows enrolments, grades, and completion per module in the selected course, while an area chart compares active, inactive, and expired enrolments across courses.

Purpose and content

A table shows enrolments, grades, and completion per module in the selected course, while an area chart compares active, inactive, and expired enrolments across courses.

Why and when to use it

Helps investigate student and module status within a course and compare enrolment counts across courses, distinguishing enrolment status from activity completion.

Filters SQL and visualizations Cautions

Available filters

The table uses the :courseid parameter provided by the course filter and restricts results to users who are not deleted or suspended, visible courses, and visible modules.

The area chart does not contain :courseid, so it is unaffected by the course selected for the table; it aggregates all courses in the query. There are no dynamic user, cohort, or date-range parameters. Enrolment end dates are compared with the current time.

Visualizations and full original SQL

This report contains 2 visualizations and 3 SQL queries. Where a visualization has separate MySQL and PostgreSQL queries, they are displayed in separate panels within the same item.

1. Enrolments, grades, and completion by module – Table

The table shows the user, course, visible module, grade when available, completion settings, completion result, and enrolment end date. A student can appear once per module.

Cache: 30m · Refresh: 30m.

Full original SQL

SELECT
    u.id AS u_id,
    u.firstname,
    u.lastname,
    u.email,
    u.city,
    u.country,
    c.id       AS c_id,
    c.fullname AS c_fullname,
    cm.id      AS cm_cmid,
    m.name AS module_name,
    ROUND(
        CASE
            WHEN g.rawgrademax > 0 THEN (g.finalgrade / g.rawgrademax) * 100
            ELSE g.finalgrade
        END, 0
    ) AS grade,
    CASE
        WHEN cmc.completionstate = 0 THEN 'lang::report_4_completionstate_0::local_kopere_bi'
        WHEN cmc.completionstate = 1 THEN 'lang::report_4_completionstate_1::local_kopere_bi'
        WHEN cmc.completionstate = 2 THEN 'lang::report_4_completionstate_2::local_kopere_bi'
        WHEN cmc.completionstate = 3 THEN 'lang::report_4_completionstate_3::local_kopere_bi'
        WHEN cmc.completionstate = 4 THEN 'lang::report_4_completionstate_4::local_kopere_bi'
        ELSE 'lang::report_4_completionstate_none::local_kopere_bi'
    END AS completionstate_status,
    CASE
        WHEN cm.completion = 0 THEN 'lang::report_4_completion_0::local_kopere_bi'
        WHEN cm.completion = 1 THEN 'lang::report_4_completion_1::local_kopere_bi'
        WHEN cm.completion = 2 THEN 'lang::report_4_completion_2::local_kopere_bi'
        ELSE 'lang::report_4_completion_none::local_kopere_bi'
    END AS completion_status,
    ue.enrol_status AS enrol_status,
    ue.timeend       AS enrol_timeend
FROM (
    SELECT MIN(ue1.id) AS id, 
           ue1.userid, 
           e1.courseid, 
           MIN(ue1.status) AS enrol_status, 
           MIN(ue1.timeend) AS timeend
    FROM mdl_user_enrolments ue1
    JOIN mdl_enrol e1 ON e1.id = ue1.enrolid
    GROUP BY ue1.userid, e1.courseid
) ue
JOIN mdl_user u 
         ON u.id = ue.userid
JOIN mdl_course c 
         ON c.id = ue.courseid
JOIN mdl_course_modules cm 
         ON cm.course = c.id
        AND cm.instance > 0
JOIN mdl_modules m 
         ON m.id = cm.module
LEFT JOIN mdl_grade_items gi 
         ON gi.itemtype = 'mod'
        AND gi.iteminstance = cm.instance
        AND gi.itemmodule = m.name
        AND gi.gradetype = 1
LEFT JOIN mdl_grade_grades g 
         ON g.itemid = gi.id
        AND g.userid = u.id
LEFT JOIN mdl_course_modules_completion cmc 
         ON cmc.coursemoduleid = cm.id
        AND cmc.userid = u.id

WHERE c.id = :courseid
  AND u.deleted = 0
  AND u.suspended = 0
  AND c.visible = 1
  AND cm.visible = 1
2. Active, inactive, and expired enrolments by course – Area chart

The area chart compares three aggregated enrolment counts per course. MySQL and PostgreSQL use different expressions for the current time but produce the same visualization.

Cache: 30m · Refresh: 30m.

Full original MySQL SQL

SELECT c.fullname,
       SUM(CASE 
               WHEN ue.status = 0 AND (ue.timeend = 0 OR ue.timeend > UNIX_TIMESTAMP()) THEN 1
               ELSE 0
           END) AS 'lang::active_enrolments::local_kopere_bi',
       SUM(CASE 
               WHEN ue.status = 1 THEN 1
               ELSE 0
           END) AS 'lang::inactive_enrolments::local_kopere_bi',
       SUM(CASE 
               WHEN ue.status = 0 AND ue.timeend > 0 AND ue.timeend < UNIX_TIMESTAMP() THEN 1
               ELSE 0
           END) AS 'lang::expired_enrolments::local_kopere_bi'
FROM mdl_course c
JOIN mdl_enrol e ON e.courseid = c.id
JOIN mdl_user_enrolments ue ON ue.enrolid = e.id
GROUP BY c.id
ORDER BY c.fullname

Full original PostgreSQL SQL

SELECT c.fullname,
       SUM(CASE 
               WHEN ue.status = 0 AND(ue.timeend = 0 OR ue.timeend > (EXTRACT(EPOCH FROM CURRENT_TIMESTAMP)::bigint)) THEN 1
               ELSE 0
           END) AS "lang::active_enrolments::local_kopere_bi",
       SUM(CASE 
               WHEN ue.status = 1 THEN 1
               ELSE 0
           END) AS "lang::inactive_enrolments::local_kopere_bi",
       SUM(CASE 
               WHEN ue.status = 0 AND ue.timeend > 0 AND ue.timeend < (EXTRACT(EPOCH FROM CURRENT_TIMESTAMP)::bigint) THEN 1
               ELSE 0
           END) AS "lang::expired_enrolments::local_kopere_bi"
FROM mdl_course c
JOIN mdl_enrol e ON e.courseid = c.id
JOIN mdl_user_enrolments ue ON ue.enrolid = e.id
GROUP BY c.id
ORDER BY c.fullname

Limitations and interpretation

  • Table rows represent enrolment and module combinations; do not use row counts as a count of distinct students.
  • The course filter affects the table but not the chart.
  • The area chart shows enrolment categories by course, not daily trends.
  • The subquery groups enrolments by user and course using MIN(status) and MIN(timeend); with multiple enrolment methods, this may combine data from different enrolments.
  • The report contains personal information and grades; grant access only to authorized roles.

The SQL was transcribed without changes from the JSON definitions on master and was not run against Moodle at this stage. Validate permissions, performance, and results in the target environment.
