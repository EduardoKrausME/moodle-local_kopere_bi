REPORT 049

Course revenue

Shows active enrolments in a visible course with a configured enrolment-method cost, including participant, record date, amount, and currency.

Report purpose

Shows active enrolments in a visible course with a configured enrolment-method cost, including participant, record date, amount, and currency.

Why use this report?

Allows administrators to review enrolments associated with priced enrolment methods, inspect configured costs, and identify where reconciliation with actual financial records is needed.

Available filters Visualization and SQL Limitations

Available filters

The dynamic SQL filter is Course, indicated by :courseid and used once in the main WHERE clause.

Fixed criteria include a configured cost (kbi_e.cost IS NOT NULL), a visible course, an account that is neither deleted nor suspended and is not guest, and enrolment and enrolment-method status 0. There are no dynamic filters for period, payment method, or transaction.

Visualization and full original SQL

One table visualization includes one SQL query, cache settings, and Prism.js syntax highlighting. The original catalog has no separate PostgreSQL variant.

1. Course revenue · Table

One row per enrolment record, showing the course, enrolment creation date, user's name and email, enrolment method, configured cost, and currency.

Cache: 1h · Refresh: none.

Full original SQL

SELECT kbi_ue.id,
       kbi_c.fullname,
       kbi_ue.timecreated,
       kbi_u.firstname,
       kbi_u.lastname,
       kbi_u.email,
       kbi_e.enrol,
       kbi_e.cost,
       kbi_e.currency
FROM mdl_user_enrolments kbi_ue
       JOIN mdl_enrol kbi_e ON kbi_e.id = kbi_ue.enrolid
       JOIN mdl_user kbi_u ON kbi_u.id = kbi_ue.userid
       JOIN mdl_course kbi_c ON kbi_c.id = kbi_e.courseid
WHERE kbi_e.cost IS NOT NULL
  AND kbi_c.id = :courseid
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username != 'guest'
  AND kbi_c.visible = 1
  AND kbi_ue.status = 0
  AND kbi_e.status = 0
ORDER BY kbi_ue.timecreated DESC, kbi_c.fullname, kbi_u.lastname, kbi_u.firstname

Limitations and cautions

  • This report does not demonstrate revenue actually received. The kbi_e.cost field is the price configured for the enrolment method; the query does not access payment, financial confirmation, or refund records.
  • The currency field indicates the currency configured for the method. Amounts in different currencies cannot be added without conversion.
  • The cost IS NOT NULL condition includes configured costs of zero; it does not require a positive cost.
  • An active enrolment does not prove that the user paid or that revenue was recognized for accounting purposes.
  • The query does not restrict enrolment validity dates or enrolment creation dates; timecreated indicates when the enrolment record was created.
  • A person may appear on multiple rows if enrolled through different methods. Adding the displayed costs does not yield an audited financial statement.
  • Because participant names and emails are included, restrict permissions and exports. The catalog has no separate PostgreSQL variant.
