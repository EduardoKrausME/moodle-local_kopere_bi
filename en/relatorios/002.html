REPORT 002

Active students

Table of non-suspended, non-deleted accounts assigned role ID 5 in a course context, including profile information, aggregated grades, and completed activities.

What this report shows

Table of non-suspended, non-deleted accounts assigned role ID 5 in a course context, including profile information, aggregated grades, and completed activities.

Why and when to use it

Provides a starting point for administrative checks of student accounts and available indicators, but does not replace course-level enrolment reports or recent activity reports.

Available filters Visualizations and SQL Limitations

Available filters

There are no dynamic SQL parameters for user, course, cohort, or date range in this report's queries, so none of those filters can alter its results.

The SQL includes fixed conditions for accounts that are not suspended or deleted and for role ID 5; these are not interactive filters.

1. Student summary table · Table

Table including user details, course data, email, access dates, calculated grade, and number of recorded completions.

Cache: 30m. Refresh: 30m.

Full original SQL

SELECT
    u.id AS u_id,
    u.firstname,
    u.lastname,
    c.id AS c_id,
    c.fullname AS c_fullname,
    u.email,
    u.lastaccess,
    u.timecreated,
    ROUND(
        AVG(
            CASE
                WHEN g.rawgrademax > 0
                THEN (g.finalgrade / g.rawgrademax) * 100
                ELSE g.finalgrade 
            END
        ), 0
    ) AS g_finalgrade,
    MAX(ca.completed_activities) AS ca_completed_activities
FROM 
    mdl_course c
JOIN 
    mdl_context ctx ON ctx.instanceid = c.id
JOIN 
    mdl_role_assignments ra ON ra.contextid = ctx.id
                            AND ra.roleid = 5
JOIN 
    mdl_user u ON u.id = ra.userid
LEFT JOIN (
        SELECT 
            COUNT(id) AS completed_activities, 
            userid
        FROM 
            mdl_course_modules_completion
        WHERE 
            id > 1
            AND completionstate IN (1, 2)
        GROUP BY 
            userid
    ) ca ON ca.userid = u.id
LEFT JOIN 
    mdl_grade_items gi ON gi.courseid = c.id 
                       AND gi.itemtype = 'course'
LEFT JOIN 
    mdl_grade_grades g ON g.itemid = gi.id 
                      AND g.userid = u.id 
                      AND g.finalgrade IS NOT NULL
WHERE u.id        > 1
  AND u.deleted   = 0
  AND u.suspended = 0
  AND u.username != 'guest'
GROUP BY u.id

Limitations and interpretation

  • The word 'active' refers to the account and role criteria, not a recent-access filter.
  • Role ID 5 is fixed; sites with custom roles should validate the query.
  • The query groups by user despite involving courses, so the output does not necessarily represent one row per enrolment.
  • The number of completed activities comes from a per-user subquery that does not restrict completions to the course in the row.
