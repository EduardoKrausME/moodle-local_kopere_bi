REPORT 044

Advanced course statistics

Expanded summary of the selected course covering enrolments, completions, grades, recorded usage, visible modules, categories, and teacher and student indicators.

Report purpose

Expanded summary of the selected course covering enrolments, completions, grades, recorded usage, visible modules, categories, and teacher and student indicators.

Why use this report?

Helps management teams compare performance indicators, activity provision, and teacher and student tracking data for a more comprehensive operational assessment of a course.

Available filters Visualization and SQL Limitations

Available filters

The effective dynamic filter is Course, indicated by :courseid and used five times in each SQL variant: in the student and grade aggregation, overall tracking, teacher query, student tracking average, and main course selection.

Fixed criteria include a visible course, enrolments and enrolment methods with status 0, student role ID 5, teacher role ID 3 in the course context, and visible modules with deletioninprogress = 0. Neither database variant defines a time filter.

Visualization and full original SQL

One table visualization includes two complete original SQL queries, cache settings, and Prism.js syntax highlighting. MySQL and PostgreSQL appear in separate panels within the same visualization.

1. Advanced course statistics · Table

The table combines the course name and identifier, average grades, enrolments and formal completions, recorded visits and time, count of visible modules not being deleted, category and parent category, associated teachers and their count, teachers' recorded time, and average recorded time for students.

Cache: 1h · Refresh: none.

Full original MySQL SQL

SELECT kbi_c.id,
       kbi_c.fullname                                                          AS course,
       kbi_c.shortname,
       kbi_c.timecreated                                                       AS created,
       kbi_c.idnumber,
       kbi_c.enablecompletion,
       kbi_c.visible,
       MAX(e.grade)                                                        AS grade,
       MAX(l.timespend)                                                    AS timespend,
       MAX(l.visits)                                                       AS visits,
       MAX(e.completed)                                                    AS completed,
       MAX(e.learners)                                                     AS learners,
       (SELECT COUNT(id) FROM mdl_course_modules WHERE course = kbi_c.id
                                                   AND deletioninprogress = 0
                                                   AND visible = 1)        AS modules,
       MAX(kbi_cat.name)                                                       AS category,
       (SELECT name FROM mdl_course_categories WHERE id = MAX(kbi_cat.parent)) AS parent_category,
       MAX(t.teachers)                                                     AS teachers,
       MAX(t.teachers_count)                                               AS teachers_count,
       MAX(t.teachers_timespend)                                           AS teachers_timespend,
       MAX(s.avg_learners_timespend)                                       AS avg_learners_timespend
FROM mdl_course kbi_c
       JOIN (SELECT kbi_e.courseid,
                    ROUND(AVG(CASE
                                WHEN kbi_g.rawgrademax > 0 THEN (kbi_g.finalgrade / kbi_g.rawgrademax) * 100
                                ELSE kbi_g.finalgrade END), 0) AS grade,
                    COUNT(DISTINCT kbi_cc.userid)              AS completed,
                    COUNT(DISTINCT kbi_ue.userid)              AS learners
             FROM mdl_enrol kbi_e
                    JOIN mdl_user_enrolments kbi_ue ON kbi_ue.enrolid = kbi_e.id
                    JOIN mdl_context kbi_ctx ON kbi_ctx.instanceid = kbi_e.courseid AND kbi_ctx.contextlevel = 50
                    JOIN mdl_role_assignments kbi_ra ON kbi_ra.contextid = kbi_ctx.id AND kbi_ra.userid = kbi_ue.userid
                    LEFT JOIN mdl_course_completions kbi_cc
                      ON kbi_cc.timecompleted > 0 AND kbi_cc.course = kbi_e.courseid AND kbi_cc.userid = kbi_ue.userid
                    JOIN mdl_grade_items kbi_gi ON kbi_gi.itemtype = 'course' AND kbi_gi.courseid = kbi_e.courseid
                    LEFT JOIN mdl_grade_grades kbi_g
                      ON kbi_g.userid = kbi_ue.userid AND kbi_g.itemid = kbi_gi.id AND kbi_g.finalgrade IS NOT NULL
             WHERE kbi_e.courseid > 0
               AND kbi_e.courseid = :courseid
               AND kbi_ue.status = 0
               AND kbi_e.status = 0
               AND kbi_ra.roleid = 5
             GROUP BY kbi_e.courseid) e ON e.courseid = kbi_c.id
       LEFT JOIN (SELECT courseid, SUM(timespend) AS timespend, SUM(visits) AS visits
                  FROM (SELECT kbi_ctx.instanceid, kbi_ra.userid
                        FROM mdl_role_assignments kbi_ra
                               JOIN mdl_context kbi_ctx ON kbi_ctx.id = kbi_ra.contextid
                        WHERE kbi_ctx.contextlevel = 50
                          AND kbi_ctx.instanceid = :courseid
                        GROUP BY kbi_ctx.instanceid, kbi_ra.userid) cu
                         LEFT JOIN mdl_local_kopere_bi_tracking kbi_ltu
                           ON kbi_ltu.courseid = cu.instanceid AND kbi_ltu.userid = cu.userid
                  WHERE cu.instanceid > 0
                  GROUP BY kbi_ltu.courseid) l ON l.courseid = kbi_c.id
       LEFT JOIN mdl_course_categories kbi_cat ON kbi_cat.id = kbi_c.category
       LEFT JOIN (SELECT ct.instanceid,
                         GROUP_CONCAT(DISTINCT CONCAT(kbi_u.firstname, ' ', kbi_u.lastname) SEPARATOR ', ') AS teachers,
                         COUNT(DISTINCT kbi_u.id)                                                       AS teachers_count,
                         SUM(timespend)                                                             AS teachers_timespend
                  FROM (SELECT kbi_ctx.instanceid, kbi_ra.userid
                        FROM mdl_role_assignments kbi_ra
                               JOIN mdl_context kbi_ctx ON kbi_ctx.id = kbi_ra.contextid
                        WHERE kbi_ctx.contextlevel = 50
                          AND kbi_ctx.instanceid = :courseid
                          AND kbi_ra.roleid = 3
                        GROUP BY kbi_ctx.instanceid, kbi_ra.userid) ct
                         JOIN mdl_user kbi_u ON ct.userid = kbi_u.id
                         LEFT JOIN mdl_local_kopere_bi_tracking kbi_lit
                           ON kbi_lit.courseid = ct.instanceid AND kbi_lit.userid = kbi_u.id
                  GROUP BY ct.instanceid) t ON t.instanceid = kbi_c.id
       LEFT JOIN (SELECT cl.instanceid, SUM(kbi_lit.timespend) / COUNT(DISTINCT(cl.userid)) AS avg_learners_timespend
                  FROM (SELECT kbi_ctx.instanceid, kbi_ra.userid
                        FROM mdl_role_assignments kbi_ra
                               JOIN mdl_context kbi_ctx ON kbi_ctx.id = kbi_ra.contextid
                        WHERE kbi_ctx.contextlevel = 50
                          AND kbi_ctx.instanceid = :courseid
                          AND kbi_ra.roleid = 5
                        GROUP BY kbi_ctx.instanceid, kbi_ra.userid) cl
                         LEFT JOIN mdl_local_kopere_bi_tracking kbi_lit
                           ON kbi_lit.courseid = cl.instanceid AND kbi_lit.userid = cl.userid
                  GROUP BY cl.instanceid) s ON s.instanceid = kbi_c.id
WHERE kbi_c.id > 0
  AND kbi_c.id = :courseid
  AND kbi_c.visible = 1
GROUP BY kbi_c.id

Limitations and cautions

  • The query uses JOIN to connect the course to aggregated enrolments, roles, and course-type grade items. Courses without matching records may be omitted even when they exist and are visible.
  • Student counts use distinct users with enrolments active according to status fields and role ID 5. Custom roles may require additional interpretation.
  • The completion total comes from mdl_course_completions with timecompleted > 0 for users in the selected enrolment population.
  • Overall recorded time and visits come from tracking for users assigned roles in the course, without limiting those roles to teachers or students.
  • The teacher list and teachers' recorded time use role ID 3. Summed time depends on tracking records and does not necessarily equal actual working hours.
  • The avg_learners_timespend average divides students' total tracked time by the number of distinct students assigned role ID 5, with no fixed time period. Null values can complicate interpretation.
  • MySQL and PostgreSQL differ in their text aggregation and numeric rounding functions. Their complete statements are therefore shown separately without modifications.
  • Grades and tracked time alone do not establish learning outcomes or the quality of educational support.
