REPORT 082

Feedback response details

Shows identified responses to Feedback activities in the selected course, including questions, answers, participant details, response modification dates, and course completion and grade indicators.

Report purpose

Shows identified responses to Feedback activities in the selected course, including questions, answers, participant details, response modification dates, and course completion and grade indicators.

Why use this report?

Allows teachers and administrators to review individual Feedback form responses and, where available, interpret them alongside course completion and course grades.

Available filters Visualization and SQL Limitations

Available filters

The dynamic SQL filter is Course, represented by :courseid and used once in kbi_mf.course = :courseid.

Fixed criteria require a visible course, a Feedback activity with a positive ID, and an identified user who is neither deleted nor suspended and is not guest. There are no filters for a particular form, question, response period, active enrolment, or course completion.

Visualization and full original SQL

One table visualization contains the complete original SQL query, cache and refresh settings, and Prism.js syntax highlighting. The catalog has no separate PostgreSQL variant for this report.

1. Feedback response details · Table

The table has one row per Feedback item and response from an identified participant. It includes participant name and email, response modification date, formal course completion date, question presentation and type, item ID, label and name, answer, form identifier, course fields, and a calculated final course grade.

Cache: 1h · Refresh: none.

Full original SQL

SELECT kbi_u.firstname,
       kbi_u.lastname,
       kbi_u.email,
       kbi_mfc.timemodified                    as feedback_time,
       kbi_cc.timecompleted,
       kbi_mfi.presentation,
       kbi_mfi.typ,
       kbi_mfi.id                              AS q_id,
       kbi_mfi.label                           AS question_number,
       kbi_mfi.name                            as question,
       kbi_mfv.value                           as answer,
       kbi_mf.name                             as feedback,
       kbi_mf.id                               as feedback_id,
       kbi_c.id                                as course_id,
       kbi_c.idnumber                          as course_idnumber,
       kbi_c.fullname                          as course_name,
       kbi_c.shortname                         as course_shortname,
       ROUND((CASE
                WHEN kbi_g.rawgrademax > 0 THEN (kbi_g.finalgrade / kbi_g.rawgrademax) * 100
                ELSE kbi_g.finalgrade END), 0) AS grade
FROM mdl_feedback kbi_mf
       JOIN mdl_course kbi_c ON kbi_c.id = kbi_mf.course
       JOIN mdl_feedback_item kbi_mfi ON kbi_mfi.feedback = kbi_mf.id
       LEFT JOIN mdl_feedback_value kbi_mfv ON kbi_mfv.item = kbi_mfi.id
       LEFT JOIN mdl_feedback_completed kbi_mfc ON kbi_mfc.id = kbi_mfv.completed
       LEFT JOIN mdl_user kbi_u ON kbi_mfc.userid = kbi_u.id
       LEFT JOIN mdl_grade_items kbi_gi ON kbi_gi.itemtype = 'course' AND kbi_gi.courseid = kbi_c.id
       LEFT JOIN mdl_grade_grades kbi_g ON kbi_g.userid = kbi_u.id AND kbi_g.itemid = kbi_gi.id AND kbi_g.finalgrade IS NOT NULL
       LEFT JOIN mdl_course_completions kbi_cc ON kbi_cc.userid = kbi_u.id AND kbi_cc.course = kbi_c.id
WHERE kbi_mf.id > 0
  AND kbi_mf.course = :courseid
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username != 'guest'
  AND kbi_c.visible = 1

Limitations and cautions

  • The query uses LEFT JOIN between responses and users, but kbi_u.deleted = 0, kbi_u.suspended = 0, and username != 'guest' in the WHERE clause exclude responses without an identified user, including anonymous responses not linked to an account.
  • Results are at the Feedback item-and-value level. One person may appear on several rows, one per answered question. The query does not summarize results by participant.
  • The feedback_time field uses mdl_feedback_completed.timemodified, which is not necessarily the original time the response was submitted.
  • The timecompleted column comes from mdl_course_completions and indicates formal course completion, not completion of the Feedback form.
  • The grade field uses grade items of type course, calculating a percentage when the maximum grade is positive and using the final grade otherwise. NULL values or extra rows are possible when several applicable grade items or records exist.
  • The answer field preserves values stored in mdl_feedback_value.value. These may be codes, choices, numbers, or text rather than values ready for statistical interpretation.
  • The query does not require active enrolment or select a reporting period. Names, email addresses, and answers are personal data and require appropriate access permissions and export safeguards.
  • No separate PostgreSQL variant is provided in the definition catalog.
