REPORT 016

Operating systems and browsers by user

Shows the percentage distribution of time recorded by Kopere BI across browsers and operating systems for each user and course.

Report purpose

Shows the percentage distribution of time recorded by Kopere BI across browsers and operating systems for each user and course.

Why use this report?

Helps support and technology teams understand the technology profile of recorded access and identify possible browser and device compatibility testing needs.

Actual filters Visualization and SQL Limitations

Available filters

There are no dynamic SQL parameters for user, course, cohort, or date range. The report groups available records by user and course and cannot restrict them using the :courseid filter with this definition.

The fixed conditions are lit.page = 'course', lit.courseid > 1, an existing visible course, and a user account that is neither deleted nor suspended and is not guest. There is no explicit date limit.

Visualization and full original SQL

The report contains one table and one SQL query, with cache, refresh settings, and Prism.js syntax highlighting. The original catalog does not provide a separate PostgreSQL variant.

1. Operating systems and browsers by user · Table

Table showing the student, course, course category, and percentages of time for Firefox, Chrome, Safari, Edge, Opera, mobile browsers, and other browser categories, as well as Windows, macOS, Linux, iOS, Android, and other platforms. Each percentage is recorded time in that category divided by total recorded time for the corresponding grouping.

Cache: 1h · Refresh: none.

Full original SQL

SELECT MAX(lit.id) AS id,
       u.id        AS userid,
       u.firstname,
       u.lastname,
       u.email,
       u.idnumber,
       c.id        AS courseid,
       c.fullname  AS course,
       cc.name     AS category_name,
       ROUND((SUM(CASE WHEN lit.useragent = 'Firefox' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS firefox,
       ROUND((SUM(CASE WHEN lit.useragent = 'Chrome' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS chrome,
       ROUND((SUM(CASE WHEN lit.useragent = 'Safari' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS safari,
       ROUND((SUM(CASE
                    WHEN lit.useragent = 'Microsoft Edge' OR lit.useragent = 'Edge' THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS microsoft_edge,
       ROUND((SUM(CASE WHEN lit.useragent = 'Opera' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS opera,
       ROUND((SUM(CASE WHEN lit.useragent = 'Mobile browser' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS mobile_browser,
       ROUND((SUM(CASE
                    WHEN lit.useragent = 'Unknown Browser' OR lit.useragent IS NULL THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS other_browser,
       ROUND((SUM(CASE WHEN lit.useros LIKE 'Windows%' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS windows,
       ROUND((SUM(CASE WHEN lit.useros LIKE 'Mac OS%' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS mac_os,
       ROUND((SUM(CASE WHEN lit.useros = 'Linux' OR lit.useros = 'Ubuntu' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS linux,
       ROUND((SUM(CASE
                    WHEN lit.useros = 'iPhone' OR lit.useros = 'iPod' OR lit.useros = 'iPad' THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS ios,
       ROUND((SUM(CASE WHEN lit.useros = 'Android' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS android,
       ROUND((SUM(CASE WHEN lit.useros = 'Mobile' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS mobile,
       ROUND((SUM(CASE
                    WHEN lit.useros = 'Unknown OS Platform' OR lit.useros IS NULL THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS other_platform
FROM mdl_local_kopere_bi_tracking lit
       LEFT JOIN mdl_course c ON c.id = lit.courseid
       LEFT JOIN mdl_course_categories cc ON cc.id = c.category
       LEFT JOIN mdl_user u ON u.id = lit.userid
WHERE lit.page = 'course'
  AND lit.courseid > 1
  AND c.id IS NOT NULL
  AND u.deleted = 0
  AND u.suspended = 0
  AND u.username != 'guest'
  AND c.visible = 1
GROUP BY lit.courseid, lit.userid, u.id, c.id, cc.id

Limitations and cautions

  • The percentages are based on the timespend field recorded by Kopere BI, not on the number of visits, sessions, distinct users, or actual learning time.
  • If total recorded time for a grouping is zero, division in the SQL may return NULL or require database-specific handling.
  • Browser and operating system categories depend on values stored in useragent and useros. Unrecognized names may not be fully represented by the predefined categories.
  • Browsers and operating systems are distinct dimensions, so percentages from those dimensions should not be added together.
  • Without a time filter, results reflect the history available in the tracking table. No independent PostgreSQL variant is supplied.
  • The table contains identifiable user information, including email addresses; restrict viewing and export permissions.
