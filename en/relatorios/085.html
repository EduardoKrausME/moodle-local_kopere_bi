REPORT 085

Course outcomes

Displays learning outcomes linked to module grade items in the selected course, including descriptions, scales, categories, and grade statistics.

Report purpose

Displays learning outcomes linked to module grade items in the selected course, including descriptions, scales, categories, and grade statistics.

Why use this report?

Helps teachers and administrators locate learning outcomes associated with graded activities and examine how many grade records exist and which average was calculated for each item.

Available filters Visualization and SQL Limitations

Available filters

The dynamic SQL filter is Course, represented by :courseid and used once in kbi_c.id = :courseid.

The fixed condition kbi_gi.itemtype = 'mod' limits results to module grade items. The query starts from mdl_grade_outcomes and does not require the course or module to be visible, active enrolments, a particular student role, account status, or a grading period.

Visualization and full original SQL

One table visualization contains the complete original SQL query, cache and refresh settings, and Prism.js syntax highlighting. The definitions catalog does not provide a separate PostgreSQL variant.

1. Course outcomes · Table

The table lists each module grade item associated with a learning outcome, including item ID, activity name, course names, outcome name and description, linked scale, course category, course start date, calculated average grade, and number of grade records.

Cache: 1h · Refresh: none.

Full original SQL

SELECT kbi_gi.id,
       kbi_gi.itemname                            as activity,
       kbi_c.shortname                            as course_shortname,
       kbi_c.fullname                             as course_fullname,
       kbi_o.fullname                             as outcome_fullname,
       kbi_o.shortname                            as outcome_shortname,
       kbi_o.description                          as outcome_description,
       kbi_sci.scale,
       kbi_ca.name                                as category,
       kbi_c.startdate,
       ROUND(AVG(CASE
                   WHEN kbi_g.rawgrademax > 0 THEN (kbi_g.finalgrade / kbi_g.rawgrademax) * 100
                   ELSE kbi_g.finalgrade END), 0) AS average_grade,
       COUNT(DISTINCT kbi_g.id)                   AS grades
FROM mdl_grade_outcomes kbi_o
       LEFT JOIN mdl_course kbi_c ON kbi_c.id = kbi_o.courseid
       LEFT JOIN mdl_course_categories kbi_ca ON kbi_ca.id = kbi_c.category
       LEFT JOIN mdl_scale kbi_sci ON kbi_sci.id = kbi_o.scaleid
       LEFT JOIN mdl_grade_items kbi_gi ON kbi_gi.outcomeid = kbi_o.id
       LEFT JOIN mdl_grade_grades kbi_g ON kbi_g.itemid = kbi_gi.id
WHERE kbi_gi.itemtype = 'mod'
  AND kbi_c.id = :courseid
GROUP BY kbi_gi.id,
         kbi_g.itemid,
         kbi_gi.itemname,
         kbi_c.shortname,
         kbi_c.fullname,
         kbi_o.fullname,
         kbi_o.shortname,
         kbi_o.description,
         kbi_sci.scale,
         kbi_ca.name,
         kbi_c.startdate
ORDER BY kbi_c.fullname, kbi_gi.itemname, kbi_o.fullname

Limitations and cautions

  • The outcomes come from mdl_grade_outcomes and the grade items associated with them. They are not automatically equivalent to competencies in the mdl_competency framework or learning plan assessments.
  • Because the WHERE clause requires kbi_gi.itemtype = 'mod', outcomes without a grade item of this type do not appear, despite preceding optional joins.
  • The grades column counts distinct IDs in mdl_grade_grades without requiring a non-NULL final grade. It is therefore not necessarily the sample size of the values actually included in AVG.
  • The average_grade column uses finalgrade / rawgrademax * 100 when the maximum grade is positive and the raw final grade otherwise. Grades from qualitative scales may not be directly comparable.
  • There is no restriction by assessment period, course visibility, or enrolment status, and the calculation does not explicitly exclude deleted or suspended users.
  • The query groups by grade item and shows descriptive outcome, scale, and category fields. It does not automatically measure competency attainment or course completion.
  • Rounding the average to zero decimal places can conceal small differences. Missing grades can yield NULL averages.
  • No separate PostgreSQL variant is provided in the definitions catalog.
