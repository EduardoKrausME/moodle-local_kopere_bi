REPORT 013

Student success and progress

Tracks students enrolled in the selected course, including grades, passing thresholds, completion, recorded access, and participation measures.

Report purpose

Tracks students enrolled in the selected course, including grades, passing thresholds, completion, recorded access, and participation measures.

Why use this report?

Helps tutors and course managers monitor each student's progress, identify potential difficulties, and compare grades, passing criteria, module completion, and recorded visits.

Actual filters Visualization and SQL Limitations

Available filters

The SQL uses only the dynamic parameter :courseid, appearing four times: when selecting enrolments, aggregating tracking data, obtaining the course grade average, and counting completed activities. This filter restricts results to the selected course.

There are also fixed conditions: enrolments and enrolment methods with status 0, student role ID 5, accounts that are neither deleted nor suspended, visible courses, and exclusion of the guest user. There are no dynamic user, cohort, or date-range filters.

Visualization and full original SQL

One table visualization with the full original SQL and its cache and refresh settings. The code uses Prism.js SQL syntax highlighting.

1. Student success and progress · Table

The table combines enrolment data, start date, enrolment method, final grade and percentage, passing threshold, course grade average, last recorded access, visits, tracked time, and formal course completion for each student and course. The query joins enrolment, grading, completion, and Kopere BI tracking information.

Cache: 1h · Refresh: none.

Full original SQL

SELECT CASE
         WHEN kbi_gi.grademax > 0 THEN (kbi_cri.gradepass / kbi_gi.grademax) * 100
         ELSE kbi_cri.gradepass END            AS gradepass,
       kbi_cri.gradepass                       AS gradepass_raw,
       kbi_u.email,
       ue.userid,
       ue.started,
       kbi_c.id                                AS cid,
       kbi_c.fullname,
       ue.enrolment,
       kbi_c.startdate,
       lit.lastaccess,
       git.average,
       ROUND((CASE
                WHEN kbi_g.rawgrademax > 0 THEN (kbi_g.finalgrade / kbi_g.rawgrademax) * 100
                ELSE kbi_g.finalgrade END), 2) AS grade,
       ROUND((CASE
                WHEN kbi_g.rawgrademax > 0 THEN (kbi_g.finalgrade / kbi_g.rawgrademax) * 100
                ELSE kbi_g.finalgrade END), 2) AS grade_raw,
       ROUND((CASE
                WHEN (kbi_g.rawgrademax - kbi_g.rawgrademin) > 0
                        THEN ((kbi_g.finalgrade - kbi_g.rawgrademin) / (kbi_g.rawgrademax - kbi_g.rawgrademin)) * 100
                ELSE kbi_g.finalgrade END), 2) AS grade_percent,
       cmc.completed,
       kbi_u.firstname,
       kbi_u.lastname,
       lit.timespend,
       lit.visits,
       kbi_c.enablecompletion,
       kbi_cc.timecompleted                    AS complete
FROM (SELECT DISTINCT kbi_e.courseid,
                      kbi_ue.userid,
                      (CASE
                         WHEN kbi_ue.timestart > 0
                                 THEN kbi_ue.timestart
                         ELSE kbi_ue.timecreated
                          END) AS started,
                      (CASE
                         WHEN kbi_e.name IS NULL
                                 THEN kbi_e.enrol
                         ELSE CONCAT(kbi_e.enrol, '(', kbi_e.name, ')')
                          END) AS enrolment
      FROM mdl_enrol kbi_e
             JOIN mdl_user_enrolments kbi_ue ON kbi_ue.enrolid = kbi_e.id
             JOIN mdl_context kbi_ctx ON kbi_ctx.contextlevel = 50 AND kbi_ctx.instanceid = kbi_e.courseid
             JOIN mdl_role_assignments kbi_ra
               ON kbi_ra.contextid = kbi_ctx.id AND kbi_ra.userid = kbi_ue.userid AND kbi_ra.roleid = 5
      WHERE kbi_ue.userid > 0
        AND kbi_e.status = 0
        AND kbi_ue.status = 0
        AND kbi_e.courseid = :courseid) ue
       JOIN mdl_user kbi_u ON kbi_u.id = ue.userid
       JOIN mdl_course kbi_c ON kbi_c.id = ue.courseid
       LEFT JOIN mdl_course_completions kbi_cc ON kbi_cc.course = kbi_c.id AND kbi_cc.userid = kbi_u.id
       LEFT JOIN mdl_course_completion_criteria kbi_cri ON kbi_cri.course = kbi_c.id AND kbi_cri.criteriatype = 6
       LEFT JOIN mdl_grade_items kbi_gi ON kbi_gi.courseid = kbi_c.id AND kbi_gi.itemtype = 'course'
       LEFT JOIN mdl_grade_grades kbi_g ON kbi_g.itemid = kbi_gi.id AND kbi_g.userid = kbi_u.id
       LEFT JOIN (SELECT kbi_lit.userid,
                         kbi_lit.courseid,
                         SUM(kbi_lit.timespend)  as timespend,
                         SUM(kbi_lit.visits)     as visits,
                         MAX(kbi_lit.lastaccess) as lastaccess
                  FROM mdl_local_kopere_bi_tracking kbi_lit
                  WHERE kbi_lit.courseid > 0
                    AND kbi_lit.courseid = :courseid
                  GROUP BY kbi_lit.courseid, kbi_lit.userid) lit ON lit.courseid = kbi_c.id AND lit.userid = kbi_u.id
       LEFT JOIN (SELECT kbi_gi.courseid,
                         ROUND(AVG(CASE
                                     WHEN (kbi_g.rawgrademax - kbi_g.rawgrademin) > 0
                                             THEN ((kbi_g.finalgrade - kbi_g.rawgrademin) / (kbi_g.rawgrademax - kbi_g.rawgrademin)) * 100
                                     ELSE kbi_g.finalgrade END), 2) AS average
                  FROM mdl_grade_items kbi_gi, mdl_grade_grades kbi_g
                  WHERE kbi_gi.itemtype = 'course'
                    AND kbi_g.itemid = kbi_gi.id
                    AND kbi_g.finalgrade IS NOT NULL
                    AND kbi_gi.courseid = :courseid
                  GROUP BY kbi_gi.courseid) git ON git.courseid = kbi_c.id
       LEFT JOIN (SELECT kbi_cmc.userid, kbi_cm.course, COUNT(kbi_cmc.id) as completed
                  FROM mdl_course_modules_completion kbi_cmc, mdl_course_modules kbi_cm
                  WHERE kbi_cm.visible = 1
                    AND kbi_cmc.coursemoduleid = kbi_cm.id
                    AND kbi_cmc.completionstate IN (1, 2)
                    AND kbi_cm.course = :courseid
                  GROUP BY kbi_cm.course, kbi_cmc.userid) cmc ON cmc.course = kbi_c.id AND cmc.userid = kbi_u.id
WHERE kbi_u.id > 0
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username != 'guest'
  AND kbi_c.visible = 1

Limitations and cautions

  • The query considers assignments of role ID 5 in the course context; institutions with custom roles should validate this condition.
  • The grade field is calculated from grading scales and recorded grades. Some indicators may be empty when assessment data is missing; do not treat missing values as zero.
  • Time, visits, and last-access data come from mdl_local_kopere_bi_tracking and depend on what was actually collected; recorded time does not equate to learning.
  • Activity completion counts states 1 and 2 for visible modules. This must not be confused with formal course completion, which appears in a separate field.
  • Joining grade items and completion criteria may multiply rows in courses with certain configurations. Check aggregations before using the results for institutional decisions.
  • The SQL is preserved as published. It contains rounding functions and other expressions whose compatibility depends on the database system and configuration. There is no separate PostgreSQL variant for this report.
