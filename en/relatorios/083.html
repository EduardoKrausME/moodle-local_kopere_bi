REPORT 083

Feedback overview

Calculates the arithmetic mean of eligible numeric responses for each Feedback activity item across all forms in the database, without restricting results to a course.

Report purpose

Calculates the arithmetic mean of eligible numeric responses for each Feedback activity item across all forms in the database, without restricting results to a course.

Why use this report?

Helps evaluation teams examine averages for numeric Feedback items, distinguishing questions with computable averages from those whose responses cannot produce one.

Available filters Visualization and SQL Limitations

Available filters

There are no dynamic SQL parameters for course, form, item, respondent, date, or reporting period.

The only fixed condition in the main query is kbi_f.id > 0. The average includes items with typ = 'numeric' or typ = 'multichoicerated' whose presentation does not begin with c>>>>>. The response must also be non-NULL, nonempty, and contain no | character.

Visualization and full original SQL

One table visualization includes the complete original SQL query, cache and refresh settings, and Prism.js syntax highlighting. There is no separate PostgreSQL variant for this report.

1. Feedback overview · Table

The per-Feedback-item table displays the item's ID, name, and the avg_value average of responses meeting the numeric eligibility conditions in the SQL. Items without eligible numeric responses may have a NULL average.

Cache: 1h · Refresh: none.

Full original SQL

SELECT kbi_fi.id,
       kbi_fi.name,
       AVG(CASE WHEN (kbi_fi.typ = 'numeric'
                    OR (kbi_fi.typ = 'multichoicerated'
                        AND kbi_fi.presentation NOT LIKE 'c>>>>>%'))
                    AND kbi_fv.value IS NOT NULL
                    AND kbi_fv.value <> ''
                    AND kbi_fv.value NOT LIKE '%|%'
                THEN CAST(kbi_fv.value AS DECIMAL(12, 4))
                ELSE NULL END) AS avg_value
FROM mdl_feedback kbi_f
JOIN mdl_feedback_completed kbi_fc ON kbi_fc.feedback = kbi_f.id
JOIN mdl_feedback_item kbi_fi ON kbi_fi.feedback = kbi_f.id
JOIN mdl_feedback_value kbi_fv ON kbi_fv.completed = kbi_fc.id AND kbi_fv.item = kbi_fi.id
WHERE kbi_f.id > 0
GROUP BY kbi_fi.id, kbi_fi.name

Limitations and cautions

  • The report does not calculate an overall satisfaction score for a course or an entire form. Results are grouped by kbi_fi.id and kbi_fi.name, meaning each individual item.
  • Text questions, ineligible items, and empty values or values containing | are excluded from AVG. The average may be NULL when no eligible values exist.
  • The expression CAST(kbi_fv.value AS DECIMAL(12, 4)) assumes that eligible answers have valid numeric representations. Unexpected values may cause errors or database-specific conversions.
  • The report includes forms from all courses. It does not filter course visibility, form status, users, or response dates.
  • Answers are retrieved through inner joins to completed response and value records, so items without recorded values do not appear even when configured in the form.
  • The SQL and presentation metadata differ: the query returns avg_value, but info.column lists only id and name. Depending on the table component, the average may not appear as a configured column.
  • The mean does not account for weighting, sample size, response distributions, or nonresponse bias.
  • There is no separate PostgreSQL definition in the original catalog.
