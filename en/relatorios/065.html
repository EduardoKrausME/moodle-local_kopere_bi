REPORT 065

Quiz attempt summary by course

Summary of quiz attempts in the selected course, including quizzes attempted, accumulated duration, average percentage score, and an associated teacher.

Report purpose

Summary of quiz attempts in the selected course, including quizzes attempted, accumulated duration, average percentage score, and an associated teacher.

Why use this report?

Supports preliminary administrative analysis of attempt volume and recorded quiz performance within a course, with comparisons across operational periods requiring analysis outside this query.

Available filters Visualization and SQL Limitations

Available filters

The dynamic SQL filter is Course, with :courseid appearing once in the WHERE clause.

The SQL requires a visible course and a positive attempt ID. The teacher subquery finds a course-context assignment for role ID 3 (contextlevel = 50) and returns at most one person using LIMIT 1. There are no fixed filters for finished attempts, active students, or a date range.

Visualization and full original SQL

One table visualization contains the original SQL query, cache and refresh settings, and Prism.js syntax highlighting. No separate PostgreSQL definition file is provided.

1. Quiz attempt summary by course · Table

One row is returned for the selected course, containing the largest attempt ID as a reference, course name, count of quizzes with attempts, total duration in seconds, distinct attempt count, average percentage score, and the name of one user with a teacher role.

Cache: 1h · Refresh: none.

Full original SQL

SELECT MAX(kbi_qa.id)                              AS id,
       kbi_c.fullname,
       COUNT(DISTINCT kbi_q.id)                    AS quizzes,
       SUM(kbi_qa.timefinish - kbi_qa.timestart)       AS duration,
       COUNT(DISTINCT kbi_qa.id)                   AS attempts,
       AVG((kbi_qa.sumgrades / kbi_q.sumgrades) * 100) AS grade,
       (SELECT DISTINCT CONCAT(kbi_u.firstname, ' ', kbi_u.lastname)
        FROM mdl_role_assignments kbi_ra
               JOIN mdl_user kbi_u ON kbi_ra.userid = kbi_u.id
               JOIN mdl_context kbi_ctx ON kbi_ctx.id = kbi_ra.contextid
        WHERE kbi_ctx.instanceid = kbi_c.id
          AND kbi_ctx.contextlevel = 50
          AND kbi_ra.roleid = 3
        LIMIT 1)                               AS teacher
FROM mdl_quiz_attempts kbi_qa
       LEFT JOIN mdl_quiz kbi_q ON kbi_q.id = kbi_qa.quiz
       LEFT JOIN mdl_course kbi_c ON kbi_c.id = kbi_q.course
WHERE kbi_qa.id > 0
  AND kbi_c.id = :courseid
  AND kbi_c.visible = 1
GROUP BY kbi_c.id

Limitations and cautions

  • The query starts from mdl_quiz_attempts; courses without attempts have no row, and quizzes only counts quizzes with at least one attempt.
  • The attempts value counts distinct attempts, not distinct participants.
  • The duration total sums timefinish - timestart without requiring finished attempts or positive durations. Open attempts can distort the result.
  • The average grade is based on the attempt's sumgrades / sumgrades of the quiz, multiplied by 100, across all attempts. The denominator is not explicitly protected when the maximum score is zero.
  • The SQL does not exclude preview attempts (preview) or require the finished state. Thus, statistics may include records that are not completed student assessments.
  • The teacher subquery selects one user with role ID 3 using LIMIT 1 but without ORDER BY. The name may vary and does not necessarily identify the person responsible for every quiz.
  • The report does not distinguish students' consolidated final grades from individual attempt scores and has no time filter or separate PostgreSQL definition.
