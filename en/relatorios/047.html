REPORT 047

Operating systems and browsers by course

Table of visible courses showing the percentage of time recorded by Kopere BI across browser and operating-system categories.

Report purpose

Table of visible courses showing the percentage of time recorded by Kopere BI across browser and operating-system categories.

Why use this report?

Helps identify dominant browsers and operating systems in each course's tracking records to inform compatibility, accessibility, and user-experience testing.

Available filters Visualization and SQL Limitations

Available filters

There are no dynamic SQL filters for course, student, period, or device. The query covers records in mdl_local_kopere_bi_tracking linked to existing visible courses with lit.courseid > 1, grouped by course and category.

Classification uses fixed comparisons of the useragent and useros fields with browser and platform names. The query has no explicit time window.

Visualization and full original SQL

One table visualization includes the complete original SQL, cache and refresh settings, and Prism.js syntax highlighting. No separate PostgreSQL variant file is available in the catalog.

1. Operating systems and browsers by course · Table

Each course row includes its category and time-based percentages for Firefox, Chrome, Safari, Edge, Opera, mobile and unknown browsers, and Windows, macOS, Linux, iOS, Android, Mobile and unknown platforms.

Cache: 1h · Refresh: none.

Full original SQL

SELECT c.id,
       c.fullname AS course,
       cc.name    AS category_name,
       ROUND((SUM(CASE WHEN lit.useragent = 'Firefox' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS firefox,
       ROUND((SUM(CASE WHEN lit.useragent = 'Chrome' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS chrome,
       ROUND((SUM(CASE WHEN lit.useragent = 'Safari' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS safari,
       ROUND((SUM(CASE
                    WHEN lit.useragent = 'Microsoft Edge' OR lit.useragent = 'Edge' THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS microsoft_edge,
       ROUND((SUM(CASE WHEN lit.useragent = 'Opera' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS opera,
       ROUND((SUM(CASE WHEN lit.useragent = 'Mobile browser' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS mobile_browser,
       ROUND((SUM(CASE
                    WHEN lit.useragent = 'Unknown Browser' OR lit.useragent IS NULL THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS other_browser,
       ROUND((SUM(CASE WHEN lit.useros LIKE 'Windows%' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS windows,
       ROUND((SUM(CASE WHEN lit.useros LIKE 'Mac OS%' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS mac_os,
       ROUND((SUM(CASE WHEN lit.useros = 'Linux' OR lit.useros = 'Ubuntu' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS linux,
       ROUND((SUM(CASE
                    WHEN lit.useros = 'iPhone' OR lit.useros = 'iPod' OR lit.useros = 'iPad' THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS ios,
       ROUND((SUM(CASE WHEN lit.useros = 'Android' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS android,
       ROUND((SUM(CASE WHEN lit.useros = 'Mobile' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS mobile,
       ROUND((SUM(CASE
                    WHEN lit.useros = 'Unknown OS Platform' OR lit.useros IS NULL THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS other_platform
FROM mdl_local_kopere_bi_tracking lit
       LEFT JOIN mdl_course c ON c.id = lit.courseid
       LEFT JOIN mdl_course_categories cc ON cc.id = c.category
WHERE lit.courseid > 1
  AND c.id IS NOT NULL
  AND c.visible = 1
GROUP BY lit.courseid, c.id, cc.id

Limitations and cautions

  • The percentages represent proportions of recorded time (timespend), not proportions of people, logins, sessions, or unique devices.
  • Each percentage divides the category's recorded time by the course's SUM(lit.timespend). When total time is zero, the SQL has no NULLIF or explicit division-by-zero protection; behavior depends on the database.
  • Browser categories are not necessarily exhaustive: values other than the recognized names are not automatically included in other_browser, which covers only Unknown Browser and NULL values.
  • The same applies to operating systems: other_platform does not include every platform outside the listed set, only Unknown OS Platform and NULL values.
  • Browser percentages and operating-system percentages are independent distributions and must not be added together.
  • User-agent and operating-system labels depend on tracking identification and normalization; devices or browsers may be classified inaccurately.
  • The query does not distinguish teachers from students and does not restrict records by date. There is no dedicated PostgreSQL file for this definition.
