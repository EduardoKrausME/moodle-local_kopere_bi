Charts, tables and filters

Eight block families and four built-in filter subplugins.

Visualization families

AreaMagnitude over time
ColumnCategory comparison
LineTime trends
PieShare of a whole

InfoSingle KPI
HTMLFormatted output
MapsApproximate IP location

Charts use ApexCharts. Tables use DataTables features such as pagination, searching, sorting, printing, clipboard copying, and CSV/Excel/PDF export, depending on configuration.

Filter types

The repository implements bifilters/course, bifilters/cohort, bifilters/period and bifilters/user. A visible filter should correspond to an actual restriction in the underlying data source; UI filtering alone must not be mistaken for data authorization.

Interpretation guidelines

  • Show the time interval and units on trend charts.
  • Explain percentage denominators.
  • Do not treat IP geolocation as precise physical location.
  • Limit personal information in shared table exports.
  • Escape untrusted data when formatting output.

Display settings

Site administrators can configure chart palettes and advanced defaults for area, column, line and pie charts. Changes to chart options should be tested because inappropriate scales and formatters can misrepresent data.
