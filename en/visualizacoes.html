Charts, tables, and filters

Available visualization types and considerations for presenting data.

Eight block families

AreaCumulative trends
ColumnComparisons across groups
LineTime series
PiePercentage distribution
TableRows, sorting, and export
InfoSingle-value indicator
HTMLFormatted content
MapsApproximate location based on IP address

Charts use ApexCharts; tables use DataTables features, including pagination, searching, and sorting, as well as printing, copying, and CSV, Excel, or PDF exports when configured.

Available filters

The filter subplugins found in the repository are bifilters/course, bifilters/cohort, bifilters/period, and bifilters/user. Choose only filters that the query actually handles; otherwise a dashboard may appear filtered while its data is incorrectly aggregated.

Best practices

  • For a time series, specify the date range and unit of measurement.
  • For percentages, explain the denominator; “30% completion” is ambiguous without a baseline.
  • Do not treat IP-based geolocation as an exact physical location.
  • Do not expose personal identifiers in exports intended for broad audiences.
  • Escape text derived from user data and avoid untrusted HTML in custom templates.

Appearance settings

The plugin administration interface provides color palettes and advanced options for area, column, line, and pie charts. These options use ApexCharts settings, so global changes need care: an unsuitable axis or formatter can distort how the data is interpreted.
