Operations and troubleshooting

Scheduled maintenance, database performance and missing-data checks.

Default cron schedule

Task Default timing
report_tables_sync Hourly, minute 10
analytics_snapshot Hourly, minute 20
ip_location_update Daily, 03:15
online_delete Daily, 06:00

These entries come from db/tasks.php. Online tracking, report sync and analytics snapshots have separate enable/disable settings.

Troubleshooting matrix

Symptom Check
Report missing DB engine, installer, prerequisites and user capabilities.
Stale Learning Analytics Cron, hourly sync, snapshots and feature flag.
Slow table SQL plan, indexes, filters, result size and cache.
Missing online activity Tracking setting, collector JavaScript and cleanup task.
Empty map IP records and approximate location data.

Report refresh tools

php local/kopere_bi/cli/refresh_analytics_reports.php --dry-run
php local/kopere_bi/cli/refresh_analytics_reports.php
php local/kopere_bi/cli/import_database_reports.php

Review dry-run output before updates, and do not assume locally customized SQL should be overwritten. Cross-check results in staging when supporting both MySQL and PostgreSQL.

Production checks

Measure costly SQL, verify cron logs, limit result size, tune cache intervals and review access to exported reports. A technically successful query is not automatically suitable for every user role.
