MOODLE PLUGIN DOCUMENTATION

Installation and upgrades

Required dependencies, plugin files, and setup in Moodle.

Prerequisites

The Moodle component is local_kopere_bi, and its code must be placed in local/kopere_bi. The dependency declared in version.php is local_kopere_dashboard, with a minimum version of 2026092300. The plugin declares a Moodle core requirement of 2024042200; also verify that your production Moodle version is compatible.

The plugin uses native Moodle features, SQL, and bundled visualization libraries. The SQL and Learning Analytics features documented here cover MySQL and PostgreSQL.

Installation

  1. First install Kopere Dashboard in local/kopere_dashboard.
  2. Place this repository in local/kopere_bi in your Moodle installation.
  3. Run the upgrade through Site administration → Notifications or via CLI.
  4. Review the local/kopere_bi:view and local/kopere_bi:manage capabilities, settings, and scheduled tasks.
php admin/cli/upgrade.php --non-interactive
php admin/cli/purge_caches.php

Run commands from the Moodle root directory, using the web server process account, with backups in place and an appropriate maintenance window.

Upgrades and bundled reports

The package installs report definitions stored in db/files/page-*.json. Upgrade procedures attempt to preserve customizations, including modified SQL and settings, while adding missing variants.

php local/kopere_bi/cli/import_database_reports.php

This importer is idempotent and adds missing pages, blocks, and elements; do not confuse it with the selective update procedure for existing reports, which is documented under Report catalog and SQL.

After installation

Verify access via Site administration → Integrations → Kopere BI, check that cron is running, and open reports compatible with your database engine. If the menu is missing, confirm the dependency, user permissions, and successful completion of the upgrade.
