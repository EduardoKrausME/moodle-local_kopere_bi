MOODLE PLUGIN DOCUMENTATION

Installation and updates

Required dependency, installation paths and Moodle setup.

Requirements

The plugin component is local_kopere_bi and belongs in local/kopere_bi. The declared dependency is local_kopere_dashboard version 2026092300 or higher; the core requirement in version.php is 2024042200. Verify the selected Moodle release in your own testing environment.

Database-aware reports and Learning Analytics documented here support MySQL and PostgreSQL.

Install

  1. Install Kopere Dashboard at local/kopere_dashboard.
  2. Install this repository at local/kopere_bi.
  3. Complete the Moodle upgrade in Site administration → Notifications or on the command line.
  4. Check local/kopere_bi:view, local/kopere_bi:manage, scheduled tasks and plugin settings. 
php admin/cli/upgrade.php --non-interactive
php admin/cli/purge_caches.php

Run the commands from the Moodle root with the correct OS account after taking backups and planning an appropriate maintenance window.

Import bundled reports

Report templates are stored under db/files/page-*.json. The upgrade adds missing report/database variants while preserving existing custom SQL and settings.

php local/kopere_bi/cli/import_database_reports.php

The importer is idempotent. For selective updates to existing analytic queries, use the separate command on the Reports page.

Verify access

Open Site administration → Integrations → Kopere BI and confirm that compatible reports load. If the menu is missing, check the dependency, the completed upgrade and the current user's permissions.
