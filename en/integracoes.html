Optional MCP report integration

Read saved Kopere BI report data through discoverable read-only tools.

How it is enabled

When the optional local_mcp plugin is installed and active, Kopere BI’s classes/mcp/provider.php is discovered automatically. Kopere BI continues to operate normally without MCP.

Discover report tools

kopere_bi_list_reports lists reports available to the current user, including IDs, titles, categories and tool names. Each saved report with a unique valid refkey can become a kopere_bi_report_<refkey> read-only tool.

{
  "name": "kopere_bi_report_learning_analytics",
  "arguments": {"course_id": 2, "limit": 50, "offset": 0}
}

The tool name is illustrative. Use kopere_bi_list_reports to get the exact refkey in your site.

Parameters and response

Supported arguments are user_id, course_id, cohort_id, limit (default 50, maximum 200 rows per element) and offset. Elements return raw rows, headings, counts and has_more, not client-side chart JavaScript.

Security guarantees

Only stored SELECT/WITH SQL sources or supported saved class-based sources run, with bound parameters and database row limits. Client-provided SQL is never executed. Moodle permissions, READ scope, page access and filters restrict discoverability and execution.

See the Kopere BI MCP technical guide for the API contract.
