RELATÓRIO 047

Sistemas operacionais e navegadores por curso

Tabela de cursos visíveis com percentuais de tempo de uso registrado pelo Kopere BI, distribuídos entre categorias de navegadores e sistemas operacionais.

Finalidade do relatório

Tabela de cursos visíveis com percentuais de tempo de uso registrado pelo Kopere BI, distribuídos entre categorias de navegadores e sistemas operacionais.

Por que utilizar?

Permite identificar a predominância de navegadores e sistemas operacionais nos registros de acompanhamento de cada curso para apoiar decisões de compatibilidade, acessibilidade e testes de experiência do usuário.

Filtros disponíveisVisualização e SQLLimitações

Filtros disponíveis

Não há filtros SQL dinâmicos de curso, estudante, período ou dispositivo. O SQL abrange registros da tabela mdl_local_kopere_bi_tracking associados a cursos existentes e visíveis, com lit.courseid > 1, agrupados por curso e categoria.

As condições de classificação são comparações fixas dos campos useragent e useros com nomes de navegadores e plataformas. A consulta não tem janela temporal explícita.

Visualização e SQL original integral

Uma visualização em tabela, com SQL original integral, cache, atualização e destaque de sintaxe por Prism.js. O catálogo de definições não possui arquivo de variante PostgreSQL separado para este relatório.

1. Sistemas operacionais e navegadores por curso · Tabela

Uma tabela por curso com a categoria e percentuais de tempo para Firefox, Chrome, Safari, Edge, Opera, navegador móvel e desconhecidos, além de Windows, macOS, Linux, iOS, Android, Mobile e plataformas desconhecidas.

Cache: 1h · Atualização: none.

SQL original integral

SELECT c.id,
       c.fullname AS course,
       cc.name    AS category_name,
       ROUND((SUM(CASE WHEN lit.useragent = 'Firefox' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS firefox,
       ROUND((SUM(CASE WHEN lit.useragent = 'Chrome' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS chrome,
       ROUND((SUM(CASE WHEN lit.useragent = 'Safari' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS safari,
       ROUND((SUM(CASE
                    WHEN lit.useragent = 'Microsoft Edge' OR lit.useragent = 'Edge' THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS microsoft_edge,
       ROUND((SUM(CASE WHEN lit.useragent = 'Opera' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS opera,
       ROUND((SUM(CASE WHEN lit.useragent = 'Mobile browser' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS mobile_browser,
       ROUND((SUM(CASE
                    WHEN lit.useragent = 'Unknown Browser' OR lit.useragent IS NULL THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS other_browser,
       ROUND((SUM(CASE WHEN lit.useros LIKE 'Windows%' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS windows,
       ROUND((SUM(CASE WHEN lit.useros LIKE 'Mac OS%' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS mac_os,
       ROUND((SUM(CASE WHEN lit.useros = 'Linux' OR lit.useros = 'Ubuntu' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS linux,
       ROUND((SUM(CASE
                    WHEN lit.useros = 'iPhone' OR lit.useros = 'iPod' OR lit.useros = 'iPad' THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS ios,
       ROUND((SUM(CASE WHEN lit.useros = 'Android' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS android,
       ROUND((SUM(CASE WHEN lit.useros = 'Mobile' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS mobile,
       ROUND((SUM(CASE
                    WHEN lit.useros = 'Unknown OS Platform' OR lit.useros IS NULL THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)   AS other_platform
FROM mdl_local_kopere_bi_tracking lit
       LEFT JOIN mdl_course c ON c.id = lit.courseid
       LEFT JOIN mdl_course_categories cc ON cc.id = c.category
WHERE lit.courseid > 1
  AND c.id IS NOT NULL
  AND c.visible = 1
GROUP BY lit.courseid, c.id, cc.id

Limitações e cuidados

  • Os percentuais representam proporções do tempo registrado (timespend), não proporções de pessoas, logins, sessões ou dispositivos únicos.
  • Cada percentual divide o tempo da categoria pelo SUM(lit.timespend) do curso. Quando o tempo total for zero, o SQL não usa NULLIF nem proteção explícita contra divisão por zero; o comportamento varia conforme o banco.
  • As categorias de navegadores não são necessariamente exaustivas: valores diferentes dos nomes verificados não entram automaticamente em other_browser, que cobre apenas Unknown Browser e valores nulos.
  • O mesmo ocorre com sistemas operacionais: other_platform não absorve todas as plataformas fora da lista, somente Unknown OS Platform e valores nulos.
  • Os percentuais dos navegadores e os percentuais dos sistemas operacionais são distribuições independentes, não devem ser somados entre si.
  • Os rótulos de user agent e sistema operacional dependem da identificação e normalização realizadas pelo tracking; dispositivos ou navegadores podem ser classificados de maneira imprecisa.
  • A consulta não distingue docentes de estudantes e não limita os registros por data. Não existe arquivo PostgreSQL específico para esta definição.
