RELATÓRIO 016

Sistemas operacionais e navegadores por usuário

Apresenta a distribuição percentual do tempo registrado pelo Kopere BI por navegador e sistema operacional, para cada usuário e curso.

Finalidade do relatório

Apresenta a distribuição percentual do tempo registrado pelo Kopere BI por navegador e sistema operacional, para cada usuário e curso.

Por que utilizar?

Ajuda equipes de suporte e tecnologia a entenderem o perfil tecnológico dos acessos registrados e identificarem possíveis necessidades de testes de compatibilidade em navegadores e dispositivos.

Filtros reaisVisualização e SQLLimitações

Filtros disponíveis

Não existem parâmetros SQL dinâmicos de usuário, curso, coorte ou período. O relatório agrupa os registros disponíveis por usuário e curso, e não permite restringi-los pelo filtro :courseid com esta definição.

As condições fixas são lit.page = 'course', lit.courseid > 1, curso existente e visível, conta não excluída, não suspensa e diferente de guest. Não há limite temporal explícito.

Visualização e SQL original integral

O relatório apresenta uma tabela e uma consulta SQL, com cache, atualização e destaque de sintaxe pela biblioteca Prism.js. Não existe variante PostgreSQL separada no catálogo original.

1. Sistemas operacionais e navegadores por usuário · Tabela

Tabela que relaciona estudante, curso, categoria do curso e percentuais de tempo para Firefox, Chrome, Safari, Edge, Opera, navegadores móveis e outras categorias, além de Windows, macOS, Linux, iOS, Android e outras plataformas. Cada percentual utiliza o tempo registrado naquela categoria dividido pelo total de tempo do respectivo agrupamento.

Cache: 1h · Atualização: none.

SQL original integral

SELECT MAX(lit.id) AS id,
       u.id        AS userid,
       u.firstname,
       u.lastname,
       u.email,
       u.idnumber,
       c.id        AS courseid,
       c.fullname  AS course,
       cc.name     AS category_name,
       ROUND((SUM(CASE WHEN lit.useragent = 'Firefox' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS firefox,
       ROUND((SUM(CASE WHEN lit.useragent = 'Chrome' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS chrome,
       ROUND((SUM(CASE WHEN lit.useragent = 'Safari' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS safari,
       ROUND((SUM(CASE
                    WHEN lit.useragent = 'Microsoft Edge' OR lit.useragent = 'Edge' THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS microsoft_edge,
       ROUND((SUM(CASE WHEN lit.useragent = 'Opera' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS opera,
       ROUND((SUM(CASE WHEN lit.useragent = 'Mobile browser' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS mobile_browser,
       ROUND((SUM(CASE
                    WHEN lit.useragent = 'Unknown Browser' OR lit.useragent IS NULL THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS other_browser,
       ROUND((SUM(CASE WHEN lit.useros LIKE 'Windows%' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS windows,
       ROUND((SUM(CASE WHEN lit.useros LIKE 'Mac OS%' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS mac_os,
       ROUND((SUM(CASE WHEN lit.useros = 'Linux' OR lit.useros = 'Ubuntu' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS linux,
       ROUND((SUM(CASE
                    WHEN lit.useros = 'iPhone' OR lit.useros = 'iPod' OR lit.useros = 'iPad' THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS ios,
       ROUND((SUM(CASE WHEN lit.useros = 'Android' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS android,
       ROUND((SUM(CASE WHEN lit.useros = 'Mobile' THEN lit.timespend ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS mobile,
       ROUND((SUM(CASE
                    WHEN lit.useros = 'Unknown OS Platform' OR lit.useros IS NULL THEN lit.timespend
                    ELSE 0 END) * 100) / SUM(lit.timespend),
             2)    AS other_platform
FROM mdl_local_kopere_bi_tracking lit
       LEFT JOIN mdl_course c ON c.id = lit.courseid
       LEFT JOIN mdl_course_categories cc ON cc.id = c.category
       LEFT JOIN mdl_user u ON u.id = lit.userid
WHERE lit.page = 'course'
  AND lit.courseid > 1
  AND c.id IS NOT NULL
  AND u.deleted = 0
  AND u.suspended = 0
  AND u.username != 'guest'
  AND c.visible = 1
GROUP BY lit.courseid, lit.userid, u.id, c.id, cc.id

Limitações e cuidados

  • Os percentuais se baseiam no campo timespend do acompanhamento do Kopere BI, não em quantidade de visitas, sessões, usuários distintos ou tempo de aprendizagem efetiva.
  • Se a soma do tempo registrado para o agrupamento for zero, a divisão usada no SQL poderá retornar NULL ou exigir tratamento específico pelo banco.
  • Categorias de navegador e sistema operacional dependem dos valores gravados nos campos useragent e useros. Denominações não reconhecidas podem não ser completamente representadas pelas categorias previstas.
  • Navegadores e sistemas operacionais são dimensões distintas, de modo que os percentuais de ambas as dimensões não devem ser somados entre si.
  • Sem filtro temporal, os resultados representam o histórico disponível na tabela de acompanhamento. O arquivo não fornece uma variante PostgreSQL independente.
  • A tabela apresenta dados identificáveis dos usuários, inclusive e-mail; limite as permissões de acesso e de exportação.
