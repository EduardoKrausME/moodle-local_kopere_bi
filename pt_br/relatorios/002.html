RELATÓRIO 002

Estudantes ativos

Tabela de contas não suspensas e não excluídas com atribuição do papel de ID 5 em contexto de curso, incluindo informações cadastrais, notas agregadas e atividades concluídas.

O que o relatório apresenta

Tabela de contas não suspensas e não excluídas com atribuição do papel de ID 5 em contexto de curso, incluindo informações cadastrais, notas agregadas e atividades concluídas.

Por que e quando utilizar

Serve como ponto de partida para a conferência administrativa de contas de estudantes e seus indicadores disponíveis, mas não substitui um relatório de matrículas por curso ou atividade recente.

Filtros disponíveisVisualizações e SQLLimitações

Filtros disponíveis

Não há parâmetros SQL dinâmicos de usuário, curso, coorte ou período nas consultas desta definição, portanto nenhum desses filtros modifica os dados neste relatório.

Há restrições fixas no SQL para contas não suspensas e não excluídas e para o papel de ID 5; elas não são filtros interativos.

Como são as visualizações e o SQL

1 consulta SQL compõe este relatório. Em cada item estão o tipo de visualização, sua finalidade, a configuração de cache e o SQL integral. Abra cada item para consultar o código.

1. Resumo tabular de estudantes · Tabela

Tabela com usuário, dados do curso, e-mail, datas de acesso, nota calculada e total de conclusões registradas.

Cache: 30m. Atualização: 30m.

SQL original integral

SELECT 
    u.id AS u_id,
    u.firstname,
    u.lastname,
    c.id AS c_id,
    c.fullname AS c_fullname,
    u.email,
    u.lastaccess,
    u.timecreated,
    ROUND(
        AVG(
            CASE
                WHEN g.rawgrademax > 0
                THEN (g.finalgrade / g.rawgrademax) * 100
                ELSE g.finalgrade 
            END
        ), 0
    ) AS g_finalgrade,
    MAX(ca.completed_activities) AS ca_completed_activities
FROM 
    mdl_course c
JOIN 
    mdl_context ctx ON ctx.instanceid = c.id
JOIN 
    mdl_role_assignments ra ON ra.contextid = ctx.id
                            AND ra.roleid = 5
JOIN 
    mdl_user u ON u.id = ra.userid
LEFT JOIN (
        SELECT 
            COUNT(id) AS completed_activities, 
            userid
        FROM 
            mdl_course_modules_completion
        WHERE 
            id > 1
            AND completionstate IN (1, 2)
        GROUP BY 
            userid
    ) ca ON ca.userid = u.id
LEFT JOIN 
    mdl_grade_items gi ON gi.courseid = c.id 
                       AND gi.itemtype = 'course'
LEFT JOIN 
    mdl_grade_grades g ON g.itemid = gi.id 
                      AND g.userid = u.id 
                      AND g.finalgrade IS NOT NULL
WHERE u.id        > 1
  AND u.deleted   = 0
  AND u.suspended = 0
  AND u.username != 'guest'
GROUP BY u.id

Limitações e interpretação

  • O nome 'ativo' reflete o critério técnico de conta e papel, não um filtro por acessos recentes.
  • O papel ID 5 é fixo; ambientes com papéis personalizados precisam validar a consulta.
  • A consulta agrupa pelo usuário mesmo envolvendo cursos, portanto as informações não representam necessariamente uma linha por matrícula.
  • O total de atividades concluídas vem de uma subconsulta por usuário sem restringir as conclusões ao curso da linha.
