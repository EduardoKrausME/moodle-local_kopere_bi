Resumo detalhado da utilização da plataforma pelos usuários

Tabela consolidada por usuário com média calculada de notas de curso, quantidade de cursos matriculados, conclusões formais e dados de tempo e visitas registrados pelo Kopere BI.

Finalidade do relatório

Tabela consolidada por usuário com média calculada de notas de curso, quantidade de cursos matriculados, conclusões formais e dados de tempo e visitas registrados pelo Kopere BI.

Por que utilizar?

Facilita obter uma visão agregada da utilização da plataforma, combinando indicadores acadêmicos de matrícula e conclusão com registros de acompanhamento por usuário para análises administrativas iniciais.

Filtros disponíveisVisualização e SQLLimitações

Filtros disponíveis

Não há filtros SQL dinâmicos de curso, usuário, coorte ou período. O resultado considera usuários com id > 0, não excluídos, não suspensos e diferentes de guest.

No agregado acadêmico são consideradas apenas matrículas e métodos de matrícula com status 0. As estatísticas de acompanhamento usam os registros disponíveis em mdl_local_kopere_bi_tracking e mdl_local_kopere_bi_track_log, sem restringir intervalo temporal.

Visualização e SQL original integral

O relatório apresenta uma tabela e 1 consulta SQL, com destaque de sintaxe pela biblioteca Prism.js. O catálogo possui apenas uma definição SQL deste relatório, sem variante PostgreSQL separada.

1. Resumo detalhado da utilização da plataforma pelos usuários · Tabela

Uma tabela por usuário com nome, e-mail, criação da conta, nota média calculada, número de cursos, cursos concluídos formalmente, tempo total registrado e visitas somadas de logs de acompanhamento.

SQL original integral

SELECT kbi_u.id,
       CONCAT(kbi_u.firstname, ' ', kbi_u.lastname) as user,
       kbi_u.email,
       kbi_u.timecreated,
       sub.grade,
       sub.courses,
       sub.completed_courses,
       lit.timespend                        AS timespend,
       lit.visits                           AS visits
FROM mdl_user kbi_u
       LEFT JOIN (SELECT kbi_ue.userid,
                         ROUND(AVG(CASE
                                     WHEN kbi_g.rawgrademax > 0 THEN (kbi_g.finalgrade / kbi_g.rawgrademax) * 100
                                     ELSE kbi_g.finalgrade END), 0) AS grade,
                         COUNT(DISTINCT kbi_e.courseid)             as courses,
                         COUNT(DISTINCT kbi_cc.course)              as completed_courses
                  FROM mdl_user_enrolments kbi_ue
                         LEFT JOIN mdl_enrol kbi_e ON kbi_e.id = kbi_ue.enrolid
                         LEFT JOIN mdl_course_completions kbi_cc
                           ON kbi_cc.timecompleted > 0 AND kbi_cc.course = kbi_e.courseid AND kbi_cc.userid = kbi_ue.userid
                         LEFT JOIN mdl_grade_items kbi_gi ON kbi_gi.itemtype = 'course' AND kbi_gi.courseid = kbi_e.courseid
                         LEFT JOIN mdl_grade_grades kbi_g
                           ON kbi_g.userid = kbi_ue.userid AND kbi_g.itemid = kbi_gi.id AND kbi_g.finalgrade IS NOT NULL
                  WHERE kbi_ue.userid > 0
                    AND kbi_ue.status = 0
                    AND kbi_e.status = 0
                  GROUP BY kbi_ue.userid) sub ON sub.userid = kbi_u.id
       LEFT JOIN (SELECT kbi_lit.userid, SUM(kbi_lil.timespend) as timespend, SUM(kbi_lil.visits) as visits
                  FROM mdl_local_kopere_bi_tracking kbi_lit
                         JOIN mdl_local_kopere_bi_track_log kbi_lil ON kbi_lil.trackid = kbi_lit.id
                  WHERE kbi_lil.id > 0
                  GROUP BY kbi_lit.userid) lit ON lit.userid = kbi_u.id
WHERE kbi_u.id > 0
  AND kbi_u.deleted = 0
  AND kbi_u.suspended = 0
  AND kbi_u.username != 'guest'

Limitações e cuidados

  • A média de notas é calculada sobre registros de avaliação disponíveis. Não representa necessariamente uma média ponderada por curso, carga horária ou créditos; usuários sem notas podem aparecer com campo vazio.
  • A quantidade de cursos distintos considera métodos e matrículas com status zero, mas não verifica explicitamente prazos de expiração ou visibilidade de cursos.
  • Os cursos concluídos são identificados por registros em mdl_course_completions com timecompleted > 0. Conclusão formal difere de concluir atividades isoladas.
  • O tempo e as visitas são agregados de logs associados à tabela de tracking. A qualidade e completude dependem da coleta e retenção do Kopere BI; tempo não equivale a engajamento pedagógico comprovado.
  • As junções entre matrículas e itens de notas podem produzir diferentes quantidades de registros, afetando a interpretação da média. Valide os indicadores antes de decisões institucionais.
  • Os indicadores podem estar ausentes para usuários sem matrículas, notas ou registros de acompanhamento. Não confunda ausência de dado com zero.
  • Não há variante PostgreSQL separada para este relatório; o SQL foi preservado exatamente como está na definição.
