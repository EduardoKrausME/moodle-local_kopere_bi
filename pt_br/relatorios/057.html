RELATÓRIO 057

Resumo estatístico das atividades

Tabela por módulo visível do curso selecionado, com tipo de atividade, data de inclusão, configuração de conclusão, total de registros concluídos e média das notas vinculadas ao módulo.

Finalidade do relatório

Tabela por módulo visível do curso selecionado, com tipo de atividade, data de inclusão, configuração de conclusão, total de registros concluídos e média das notas vinculadas ao módulo.

Por que utilizar?

Oferece uma visão das atividades e recursos do curso, ajudando administradores e docentes a identificar módulos com dados de conclusão e notas e a observar as configurações associadas.

Filtros disponíveisVisualização e SQLLimitações

Filtros disponíveis

O filtro SQL dinâmico é Curso, implementado por :courseid, presente uma vez na condição kbi_cm.course = :courseid.

O SQL exige módulo com ID positivo e kbi_cm.visible = 1. O agregado de conclusão considera completionstate IN (1, 2); as médias de nota utilizam itens do tipo mod com finalgrade IS NOT NULL. Não há parâmetros para usuário, data ou tipo de módulo.

Visualização e SQL original integral

O relatório apresenta uma visualização em tabela com 1 consulta SQL, cache e configuração de atualização, com destaque de sintaxe pelo Prism.js. O catálogo não possui arquivo de variante PostgreSQL separada para este relatório.

1. Resumo estatístico das atividades · Tabela

Uma tabela por módulo do curso selecionado, mostrando seu identificador, tipo de módulo, data de criação, configuração de conclusão, quantidade de registros de conclusão em estados 1 ou 2 e média percentual das notas finais disponíveis para itens de avaliação ligados ao módulo.

Cache: 1h · Atualização: none.

SQL original integral

SELECT kbi_cm.id, kbi_m.name AS moduletype, kbi_cm.added, kbi_cm.completion, kbi_c.fullname, cmc.num_compl AS completed, grd.grade
FROM mdl_course_modules kbi_cm
       JOIN mdl_modules kbi_m ON kbi_m.id = kbi_cm.module
       JOIN mdl_course kbi_c ON kbi_c.id = kbi_cm.course
       LEFT JOIN (SELECT coursemoduleid, COUNT(id) AS num_compl
                  FROM mdl_course_modules_completion
                  WHERE id > 0
                    AND completionstate IN (1, 2)
                  GROUP BY coursemoduleid) cmc ON cmc.coursemoduleid = kbi_cm.id
       LEFT JOIN (SELECT kbi_gi.iteminstance,
                         kbi_gi.itemmodule,
                         ROUND(AVG(CASE
                                     WHEN kbi_g.rawgrademax > 0 THEN (kbi_g.finalgrade / kbi_g.rawgrademax) * 100
                                     ELSE kbi_g.finalgrade END), 0) AS grade
                  FROM mdl_grade_items kbi_gi
                         JOIN mdl_grade_grades kbi_g ON kbi_g.itemid = kbi_gi.id AND kbi_g.finalgrade IS NOT NULL
                  WHERE kbi_gi.itemtype = 'mod'
                  GROUP BY kbi_gi.iteminstance, kbi_gi.itemmodule) grd
         ON grd.itemmodule = kbi_m.name AND grd.iteminstance = kbi_cm.instance
WHERE kbi_cm.id > 0
  AND kbi_cm.visible = 1
  AND kbi_cm.course = :courseid

Limitações e cuidados

  • O resultado apresenta módulos visíveis do curso, mas não impõe explicitamente kbi_c.visible = 1. Módulos de cursos ocultos podem entrar na consulta quando seus próprios registros de visibilidade estiverem ativos.
  • A coluna completed é uma contagem de registros de conclusão dos módulos, não de usuários únicos em toda a plataforma nem de conclusão formal do curso.
  • O agregado de conclusão usa estados 1 e 2 sem exigir que a atividade tenha completion > 0 na consulta de contagem.
  • A média grade se baseia em notas finais existentes de itens de avaliação do tipo mod; módulos que não geram notas podem apresentar valores nulos.
  • Quando rawgrademax > 0 a média usa um percentual; se não for positivo, utiliza a nota final diretamente. O resultado não representa necessariamente a mesma escala para todos os módulos.
  • O SQL não restringe a média apenas a estudantes atualmente matriculados e nem a uma janela temporal; participantes sem inscrição vigente podem ter notas consideradas.
  • São fornecidos ID e tipo de módulo, mas não o nome textual da atividade na consulta principal. Não existe arquivo PostgreSQL separado para este relatório.
